# v1.12.17

## ✨ 新增:页脚 Logo + 公告横幅增强 + 推荐商品排序

### 1. 页脚 Logo 可更换(店铺设置 → 站点信息)

页脚品牌区(原先硬编码 Z 字方块)改为**优先显示自定义 Logo 图片**(后台「站点 Logo」上传),
无 Logo 时回退 Z 字方块——与页头逻辑一致。

**验证**:上传 `site_logo` 后页脚显示对应图片 ✓。

### 2. 公告展示增强(参考 acg-faka)

公告功能(后台「店铺公告」→ 前台顶部展示)已存在,本次增强视觉:
- 从朴素文本条改为**渐变醒目横幅**(primary → blue 渐变 + 📢 图标)。
- `whitespace-pre-line` 支持换行/多条公告文本。

**验证**:后台设置公告 → 前台顶部显示渐变横幅 ✓。

### 3. 推荐商品支持排序

推荐商品接口 `featured()` 原先用 `latest()`(按创建时间),忽略后台设置的 sort。

改为 `orderByDesc('sort')` —— **按后台 sort 降序**(大号在前),sort 相同按最新。
后台「商品管理」列表可直接编辑每行 sort,改完即生效。

**验证**:4 个推荐商品 sort=50/40/30/20 → 接口按 sort 降序返回 ✓。
