## 🐛 修复:SPA 入口 index.html 被缓存导致更新后仍显示旧界面

**根因**:`NoCacheHtml` 中间件从未生效 ——
`/admin` 由 web 服务器(nginx/PHP 内置服务器)直接以静态文件返回,
请求**不进 Laravel**;且 `response()->file()`(BinaryFileResponse)的
Content-Type 延迟到 prepare() 阶段才写入,中间件读取恒为空。
结果:index.html 无防缓存头,被浏览器/nginx 启发式缓存,
更新代码后仍加载旧 JS chunk(如设置页缺「帮助中心/填入示例」等新功能)。

**修复**(双保险):
- 双端 vite 构建时向产物 `index.html` 注入
  `<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">`,
  任何部署方式都生效。
- `NoCacheHtml` 中间件加固:兼容 BinaryFileResponse(按文件 MIME/路径判断)。

> ⚠️ 升级部署后请**强刷一次浏览器缓存**(Cmd/Ctrl+Shift+R)或清理 nginx 缓存,
> 使旧的 index.html/chunk 缓存失效;此后不再复发。
