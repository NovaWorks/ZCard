# v1.9.30

## ✨ 本次更新内容

### 1. 优化:在线更新页面

- 移除「最新版本更新日志」卡片，页面更清爽（当前版本状态卡 + 版本历史时间线）
- 「当前版本」处新增 **📄 查看当前版本说明** 按钮，点击弹窗展示当前版本的更新日志

### 2. 修复:手机端访问首页不显示分类

前台首页侧边栏模式（sidebar）下，分类树在移动端（<768px）被隐藏，手机用户完全看不到分类。
已新增**移动端横向分类条**（滚动胶囊，含图标），点击即可按分类筛选；pills/combo 模式不受影响。

### 3. 新增:商品描述 Markdown/HTML 编辑器

后台商品新增/编辑的「商品描述」由纯文本框升级为 **md-editor-v3** 编辑器：
- 支持 Markdown 与 HTML 语法（预览区渲染）
- 工具栏可切换「编辑 / 预览 / 分屏」模式（所见即所得）
- 编辑区为纯代码（源码）模式
- 保存时自动用 marked 将 Markdown 编译为 HTML 入库，前台 `v-html` 直接渲染

## ⬆️ 升级

在线更新：后台 → 在线更新 → 一键更新。**无数据库迁移**，`public/storefront`、`public/admin` 产物已随仓库更新。
