# v1.12.1

## 🐛 修复

- **靓号导入格式提示显示原始键名**：sysadmin 卡密导入页「靓号自选」的格式示例/提示
  未定义 i18n 键，直接显示 `zcard.card.premiumFormatExample`。已补齐中英文
  （`cardTypePremium` / `premiumFormatHint` / `premiumFormatExample`）。

## ✨ 靓号自选增强（v1.12.0 体验优化）

- **靓号去重保护**：导入时校验靓号第一段**全局唯一**（跨商品），重复号计入失败并写 error_log；
  同批内重复、与库中已存在重复均拦截。新增 `cards.number_hash`（靓号 sha256，唯一索引）字段。
- **靓号列表分页 + 搜索**：详情接口 `premium_numbers` 改为分页结构
  （`{ list, total, page, per_page, has_more, min_price, min_price_display }`），
  前端弹窗新增搜索框与「加载更多」；深链到收银台时按 `card_id` 精确回查，翻页后不再丢号。
- **价格区间展示**：详情页与商品卡片对靓号商品显示「¥最低价 起」，而非单一定价。
- **结算确认**：收银台含靓号时，提交前弹出确认框，展示所选号码 + 单价，二次确认后下单。
- **购物车不合并不同靓号**：按 `card_id` 精确匹配，同一商品多个靓号各自成行、数量固定 1。
- **靓号详情页隐藏 SKU/数量区**：避免与靓号购买方式混淆。
