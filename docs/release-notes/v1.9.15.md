# v1.9.15

## 🔧 本次更新内容

### 1. 个人中心:自助 API 对接(供货商自助)

下游对接方无需联系管理员，登录个人中心即可自助开通供货对接：

- 个人中心新增「**API 对接**」板块：
  - 显示**供货余额** + 充值入口
  - 展示**接口地址 / App ID / App Key**，支持复制、显示/隐藏、重置
  - 内嵌可折叠**对接文档**（4 头签名对接步骤）
- 自助凭证接口：`GET /api/supplier-account/me`（无则自动创建）、`/secret`（查看 App Key）、`/regenerate`（重置）
- **自助充值**：充值页支持选择充值目标（个人余额 / 供货余额），供货余额用于 API 供货扣款（记供货账本）

### 2. 修复:后台菜单布局切换(混合/双列)菜单不显示

- 根因：布局容器未按菜单类型渲染对应菜单组件，`top-left`（混合）/`top`（顶栏）布局下顶栏一级菜单完全缺失
- 修复：布局容器按 `menuType` 动态渲染（左侧 / 混合 / 顶栏 / 双列），各布局菜单均正常显示

### 3. sysadmin 快捷入口清理

- 删除卡片：分析页 / 礼花效果 / 聊天 / 哔哩哔哩
- 「官方文档」→「**安装文档**」：点击新窗口打开 GitHub 部署安装指南
- 「更新日志」：点击新窗口打开 GitHub release-notes 目录
- 「技术支持」：点击新窗口打开 Telegram（t.me/ZhonCard）
- 禁用聊天窗口 / 礼花效果全局组件

## ⬆️ 升级

> 在线更新：后台 → 在线更新 → 检查版本 → 一键更新即可（Git-based）。

```bash
# 手动方式
git pull origin main
php artisan migrate --force        # 新增 supplier_accounts.user_id + recharges.target
php artisan route:clear && php artisan config:clear
```

> ⚠️ **本次有数据库迁移**（自助供货账号 / 充值目标），请务必执行 `php artisan migrate --force`（在线更新会自动执行）。
