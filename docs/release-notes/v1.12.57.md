# v1.12.57

## 在线更新同步修复

- 修复部分服务器缺少 Git 远程跟踪配置时，`git fetch origin main` 只更新 `FETCH_HEAD`、未更新 `origin/main`，随后又重置到旧提交而反复提示更新的问题。
- Git 拉取现在会显式刷新 `origin/main`，并以本次拉取的 `FETCH_HEAD` 作为重置目标。
- 更新完成前新增 Git 提交校验，当前 `HEAD` 与本次拉取结果不一致时不再返回更新成功。
- `VERSION` 作为发布元数据不再被当作用户修改备份或恢复，并自动清理旧更新器遗留的 `VERSION` 备份。

## 失败检测与恢复

- Composer 安装改为严格检查进程退出码；依赖安装失败时立即终止更新，不再继续显示“更新完成”。
- Composer 失败提示会明确要求检查服务器是否使用 Composer 2.2 或更高版本。
- Git 更新、Git 回退均严格检查进程退出码，并在错误信息中保留退出码和命令输出。
- Git 同步或 Composer 安装失败时，会恢复本次更新前备份的用户文件，避免配置改动因失败流程丢失。

## 回归测试

- 新增 Git 远程引用同步、关键命令失败中止、`VERSION` 不被恢复的自动化测试。
