# v1.9.32

## 🐛 修复

### 1. 货源导入:全选分类只导入部分商品

**现象**：上游商品较多时，「拉取商品」弹窗显示不全、全选某个分类导入却只成功少数几个。

**根因**：导入接口 `listProducts(null, 1)` 只拉取上游**第 1 页**（每页 50 条），
上游商品超过 50 个时，选中商品不在第 1 页即被跳过；预览弹窗同样只加载第 1 页。

**修复**：导入与预览均改为**循环分页拉取上游全部商品**（上限 20 页防御上游异常死循环），
全选/跨页商品均可完整导入。

### 2. 货源预览:上游价显示为批发最低价,与上游不一致

**根因**：预览弹窗的"上游价"取了拿货成本（批发价 `factory_price`），而上游页面展示的是
售价 `price_amount`。

**修复**：预览行拆分语义——上游参考价显示**上游售价**（与上游页面一致），
我方售价仍按**拿货成本加价**计算。展示如 `¥5.00(上游) → ¥6.00(我方)`。

### 3. 店铺设置-货源对接排版优化

「店铺设置 → 货源对接」开关与说明文字间距过近、页面紧凑。
已优化：开关与说明文字留出间距、说明换行块级显示、表单项行距加大。
