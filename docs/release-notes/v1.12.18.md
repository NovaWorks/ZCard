# v1.12.18

## ✨ 新增:手续费明细提示(付款前明确原价+手续费+应付)

### 背景

客户承担手续费时,用户看到「商品 8.8 点击付款变 9.24」会困惑,以为被多扣钱。
本次在**付款前**明确展示手续费明细。

### 实现

- **`PaymentController::channels()`**:支付渠道接口返回 `fee` / `fee_type` / `fee_bearer`。
- **`storefront/src/utils/fee.ts`**:新增 `calcChannelFee()`(与后端 `PaymentService::calcFee` 同逻辑)。
- **收银台 Checkout**:合计区展示「手续费 +¥x」明细行,应付总额与提交按钮金额含手续费。
- **充值支付页 RechargePay**:渠道列表展示「充值 ¥x + 手续费 ¥y = 应付 ¥z」提示。
- i18n:`order.checkout.feeLabel` + `recharge.feeTip`(中英文)。

### 展示效果

**收银台**:
```
小计 (1)     ¥6.50
手续费       +¥0.33
应付总额     ¥6.83
提交订单 ¥6.83
```

**充值支付页**:
```
充值 ¥100.00 + 手续费 ¥5.00 = 应付 ¥105.00
```

### 行为说明

- **仅客户承担**(fee_bearer=customer)时展示明细;商户承担时不展示(金额不变)。
- 前端计算与后端 `calcFee` 完全一致(percent = 金额×fee/100;fixed = fee×100)。
