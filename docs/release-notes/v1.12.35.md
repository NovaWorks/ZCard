# v1.12.35

## ✨ 新增:全站 SEO 支持(站点级 + 商品级)

客户需要卡网支持 SEO:可设置标题/头部信息/搜索关键词,且每个商品展示
分类、商品名、关键词、简要信息。

### 1. 站点级 SEO(后台 → 店铺设置 → 站点信息)

- 新增「**SEO 关键词**」配置(默认内置常用词,逗号分隔)。
- 前端默认输出:`<title>`(站点名)、`meta description`、`meta keywords`、
  Open Graph(og:title/description/type) —— 每页自动注入/更新。

### 2. 商品级 SEO(后台 → 商品管理 → 编辑 → SEO 设置)

- 商品新增 `seo_title` / `seo_keywords` / `seo_description` 三个自定义字段
  (迁移 `2026_08_10_082406_add_seo_fields_to_products_table`)。
- **留空自动组合**:标题 = 商品名;关键词 = 分类名 + 商品名;描述 = 商品描述前 150 字(去 HTML)。
- 前台商品详情页动态输出:`<title>商品名 - 站点名</title>`、keywords、description、
  og:image(商品封面)、og:type=product。

### 3. 前端 SEO 机制(storefront)

- 新增 `utils/seo.ts`:统一管理 title/description/keywords/OG 标签(幂等 upsert/移除)。
- 路由切换后自动重置为站点默认(防止商品页 SEO 残留到其他页)。
- 商品加载后覆盖为商品 SEO。
