# v1.12.30

## 📖 文档:明确「生产必须启动队列进程」+ 新增拿货故障排查

线上事故:顾客下单支付后未从上游拿到卡密。
排查确认**拿货链路依赖队列进程**(`QUEUE_CONNECTION=database`),
而部署文档此前**完全没有说明需要启动 `queue:work`**。

  (上游货源拿货 / 大批量卡密导入),并说明**队列不运行 = 订单已支付但永远拿不到上游卡密**。

  `supply|upstream` 日志)、解决方案(启动队列自动补发、失败任务处理、重试用尽标记发货失败)。
