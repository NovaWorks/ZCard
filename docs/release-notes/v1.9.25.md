# v1.9.25

## ✨ 本次更新内容

### 1. 修复:前台分类图标不生效

后台已设置分类图标但前台不显示。根因：前台分类接口 `GET /api/categories`
查询时字段白名单漏了 `icon`。已补上，前台分类导航（pills/sidebar/combo）图标正常显示。

### 2. 新增:优惠券批量删除

- 后台「优惠券」列表新增多选复选框 + 「批量删除」按钮（显示选中数量）
- 新增接口 `POST /api/admin/coupons/batch-delete`（`{ids: []}`），**已使用的自动跳过**，
  删除结果（删除数/跳过数）实时提示

### 3. 修复:会员等级列表表头换行

「会员等级」列表表头长文案（如 `Upgrade Threshold (Recharge)`）在固定列宽下被迫换行成多行。
已改为：表头单行不换行（`nowrap`）+ 列宽随内容自适应（固定宽度改 `min-width`）+ 超长内容省略号提示。

### 4. 优化:前台分类移到搜索框上方

前台首页布局调整：`pills`（顶部胶囊）/ `combo`（抽屉）模式下，分类导航**全宽置顶**，
显示在「搜索商品名称/关键词」上方；`sidebar`（左侧树）模式保持左右并排不变。

### 5. 新增:商品图片放大/旋转/关闭

- **前台商品详情**：lightbox 图片预览新增工具栏——放大/缩小/旋转 90°/还原，
  保留左右箭头切图、ESC/点击关闭，底部显示缩放比例与角度
- **后台商品管理**：统一图片查看器（放大/旋转/关闭）——
  列表封面、编辑抽屉封面（点击放大）、详情图（点击预览，多图可切换）

## ⬆️ 升级
