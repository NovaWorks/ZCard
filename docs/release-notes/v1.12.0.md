# v1.12.0

## ✨ 新功能:卡密「靓号自选」模式

支持虚拟商品以「靓号自选」方式售卖(如手机号、靓号等按号定价的商品):

### 后台使用流程

1. **商品设置**:商品编辑 → 价格与库存 → 购买方式选择「靓号自选」
2. **导入卡密**:卡密管理 → 导入 → 卡密类型选择「靓号自选」,每行格式为:

```
18888888888---50---含2月接码
19999999999---80---含3月接码
13800138000---30---普通
```

- **第一段**:靓号(展示给客户)
- **第二段**:该靓号价格(元)
- **第三段起**:其他信息(支付后作为卡密内容发给客户)

### 前台购买流程

1. 商品详情页点「立即购买」或「加入购物车」→ **弹出靓号选择弹窗**
2. 弹窗展示所有可选靓号及各自价格(按价格升序),**必须选一个**才能继续
3. 下单金额 = 所选靓号的价格;支付后整行内容作为卡密发送

### 技术实现

- 数据库:`products.pick_type`(general/premium)、`cards.price`(靓号单价分)
- `CardImportService`:card_type=靓号自选时解析 `---` 分隔格式提取价格
- `ProductController::show`:返回 `pick_type` 与 `premium_numbers`(未使用卡密解析的靓号+价格)
- `OrderService::createOrder`:支持 `card_id` 指定锁卡,金额=靓号价格,并发保护
- 前端:详情页靓号选择弹窗、购物车项携带 card_id、收银台透传

### 测试

新增 `PremiumPickTest` 5 用例:靓号导入价格解析、详情接口靓号列表、指定靓号锁卡与价格、缺少 card_id 拒绝、重复锁卡拒绝。
