# v1.12.45

## ✨ 扫码支付结果页:显示支付金额 + 订单倒计时

**需求**:当面付二维码页面展示支付金额,并显示订单倒计时
(后台「订单超时关闭(分钟)」设置值,默认 15 分钟)。

**实现**(`storefront/src/views/PayResult.vue`):

- **支付金额**:轮询到订单后显示应付金额(含展示货币换算)。
- **订单倒计时**:
  - 读取后台 `order_close_minutes`(店铺设置 → 交易设置 → 订单超时关闭(分钟)),
    默认 15。
  - 以订单创建时间 `created_at` + 超时分钟数为截止时间,每秒递减显示 `MM:SS`。
  - 倒计时归零提示「订单已超时,请重新下单」。
  - 组件卸载自动清理定时器。
- 中英双语文案。

> 注:倒计时为前端展示;实际超时关闭由服务器计划任务(部署指南第 4.5 步
> Cron `schedule:run`)执行,两者分钟数同源(同一后台设置)。
