# v1.9.33

## 🐛 修复:下单/登录/注册验证码不显示

**现象**：后台开启「启用人机验证」后，下单页（收银台）、登录页、注册页的验证码不显示（破图/空白）。

**根因**：前端把 `/api/captcha/{scene}` 接口直接作为 `<img src>`，但该接口返回的是
`{"src":"http://.../captcha/xxx?..."}` JSON（真正的验证码图片在 src 指向的图片路由），
浏览器加载 JSON 导致图片无法渲染。

**修复**：三处验证码刷新逻辑先请求接口获取 `{src}`，再把图片地址赋给 `<img>`——
下单（`captcha/trade`）、登录（`captcha/login`）、注册（`captcha/register`）。

验证码显隐仍由后台「店铺设置 → 启用人机验证」开关控制（trade_captcha）。
