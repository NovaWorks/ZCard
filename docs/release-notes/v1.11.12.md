# v1.11.12

## 📄 更新:部署安装指南补充常见问题排查

`docs/部署安装指南.md` 新增 3 个高频问题排查(基于近期生产环境实际案例):

### 问题 10:上传的图片 / `/storage/...` 访问 403「访问被拒绝」

- **根因**:`public/storage` 软链接缺失或指向错误,`/storage/` 请求被 Laravel 路由接管返回 403
- **解决**:`php artisan storage:link` 重建链接;Docker 环境在容器内执行
- **预防**:v1.11.11 起安装流程自动建链接;升级旧站需手动执行一次

### 问题 11:`composer install` 报 `Your lock file does not contain a compatible set of packages` / `symfony/yaml requires php >=8.4.1`

- **根因**:① 服务器 composer.lock 是旧版(锁了要求 PHP 8.4 的 Symfony 8.x);② 缺 `ext-bcmath` 扩展
- **解决**:`git reset --hard origin/main` 同步 lock + 安装 bcmath 扩展
- **预防**:v1.11.3 起 Symfony 锁定 7.4 + `config.platform.php=8.3.0`;优先用在线更新

### 问题 12:`composer install` 报 `/tmp/.composer/config.json is not readable`

- **根因**:Composer 全局配置目录被其他用户创建,运行用户无读权限
- **解决**:删 `/tmp/.composer` 或显式 `COMPOSER_HOME` 指向项目内目录
- **预防**:v1.11.4 起 `config.home` 已指向项目内 `.composer/`
