# v1.12.72

## ⚡ 货源同步改为异步任务(解决大货源同步超时 HTTP 522)

**反馈**:货源商品数量多时,点同步直接 HTTP 522 超时(同步执行,请求挂起)。

**方案**(异步任务 + 定时兜底 + 任务弹窗):

### 1. 同步改为异步任务
- 点「同步商品」→ 立即返回任务 ID(不再挂起请求),由队列 worker 后台入库;
- 同一货源有进行中任务时拒绝重复派发(409);
- 生产环境需 `queue:work` 常驻(部署指南已要求;定时同步由 `php artisan schedule:run` 触发)。

### 2. 任务状态与进度(新增 supply_sync_tasks 表)
- 状态流转:排队中 → 同步中 → 已完成/失败/已取消;
- 实时进度:已处理 N / 总数 M(每 50 个商品刷一次,分页拉取中累加);
- 计数:新增 X / 更新 Y / 隐藏 Z;失败原因截断展示。

### 3. 同步任务弹窗
- 点「同步商品」自动弹出任务窗口:状态标签 + 进度条 + 计数 + 错误信息;
- **取消任务**:置取消标记,Job 感知后立即停止(排队中/同步中均可取消);
- **重新同步**:任务结束后一键再跑;
- 历史任务列表(最近 20 条);进行中任务 3 秒轮询自动刷新。

### 4. 定时同步接入任务表
- 每小时增量同步(auto_sync 开启的货源)同样建任务记录,统一在弹窗查看历史;
- 定时同步与手动同步互斥(进行中自动跳过)。
