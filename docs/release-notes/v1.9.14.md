# v1.9.14

## 🔧 本次更新内容

### 1. 订单查询常见问题(FAQ)后台可配置

前台「订单查询」页底部的常见问题（FAQ）**不再写死**，可在后台自由增删改：

- 后台 → 店铺设置 → 交易设置 → **订单查询常见问题**：可添加/删除问题，编辑问题与答案
- 前台订单查询页优先展示后台配置的 FAQ；未配置时回退系统内置文案

### 2. 商品缺货筛选

- 商品管理列表搜索栏新增**库存状态**筛选：缺货 / 有货
- 工作台「缺货商品」快捷入口：点击后跳转到商品列表并**自动勾选缺货筛选**，直接查看缺货商品

### 3. 分类图标选择器修复

分类管理的自选图标弹层**点一下就消失、无法选择**的问题已修复，可正常切换分组并选择图标。

### 4. 货源对接帮助文字排版

货源对接表单里的帮助文字颜色统一调整为灰色，排版更清晰，不再杂乱。

## ⬆️ 升级

> 在线更新：后台 → 在线更新 → 检查版本 → 一键更新即可（Git-based）。

```bash
# 手动方式
git pull origin main
php artisan route:clear && php artisan config:clear
```

**无数据库迁移**（新增配置项自动走默认值），`public/admin`、`public/storefront` 编译产物已随仓库更新。

- 分类图标选择器修复
- 货源对接帮助文字排版优化
