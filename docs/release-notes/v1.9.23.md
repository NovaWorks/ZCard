# v1.9.23

## ✨ 本次更新内容

### 1. 新增:OKPay 虚拟货币支付驱动（USDT/TRX）

基于 dujiao-next 参考实现（`gateway/okpay`）对接，用于替代/补充 TRC20 收款场景：

- 下单：`POST {gateway}/payLink`，参数 `unique_id` / `amount` / `return_url` / `callback_url` / `coin` / `name` / `id`
- 签名：参数按 key 排序 → `key=value&…&token=商户密钥` → **md5 大写**
- 回调：form 或 JSON 均可，外层 `status=success` + `data.status=1` 判定支付成功
- 回调验签：`data[...]` 扁平键展开 + 商户 ID 软校验（参考 `VerifyCallback` 的排序签名分支）
- 金额：回调 `data.amount`（币）→ × 汇率 × 100 反算回「分」
- 配置项：`gateway_url`（默认官方地址）/ `merchant_id` / `merchant_token` / `coin`（USDT|TRX）/ `exchange_rate` / `display_name`

### 2. 新增:TokenPay 虚拟货币支付驱动（USDT）

基于 dujiao-next 参考实现（`gateway/tokenpay`）对接：

- 下单：`POST {gateway}/CreateOrder`（JSON），参数 `OutOrderId` / `OrderUserKey` / `ActualAmount` / `Currency` / `NotifyUrl` / `RedirectUrl`
- 签名：去掉 `Signature`/空值 → 按 key 排序 → `key=value&…` 直接追加 `notify_secret`（无分隔符）→ **md5 小写**
- 回调：JSON，`Status=1` 判定支付成功，同签名算法验签
- 金额：回调 `ActualAmount`（币）→ × 汇率 × 100 反算回「分」
- 配置项：`gateway_url` / `notify_secret` / `currency`（默认 USDT）/ `exchange_rate`

### 3. 基础设施

- 新增迁移 `2026_08_05_000020_add_okpay_tokenpay_channels`：幂等预置 `okpay` / `tokenpay` 两个支付通道（默认关闭，后台开启后配置密钥即可用）
- 驱动自动发现（`discoverDrivers()` 扫描 `Drivers/` 目录），后台「支付渠道」页自动出现新驱动，无需改前端
- 新增单元测试 `tests/Unit/VirtualCoinDriverTest.php`（6 用例）：签名对照参考实现、下单跳转、回调验签
