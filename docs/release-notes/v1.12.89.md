# v1.12.89

## 🛠 客服脚本受信域名白名单：输入容错与自动规范化

**客户反馈**：后台「在线客服 → 受信域名白名单」填写了 `app.chatwoot.com.cdn.chatwoot.com.client.crisp.chat,s`（多个域名被点号连成一段 + 尾随残字符）后，客服脚本不生效。

**根因**：白名单按逗号切分后，整串被当成一个非法域名，Chatwoot/Crisp 代码引用的官方域名不在列表内 → 脚本被安全机制整段丢弃（防注入逻辑按设计工作，但输入格式误伤）。正确填法应是英文逗号分隔（`app.chatwoot.com,client.crisp.chat`），或直接**留空使用默认官方域名**。

**修复内容（两端容错）**：

- 后端 `ServiceWidgetScript::normalizeHosts` 统一解析：
  - 支持逗号/空格/分号/全角逗号分隔；
  - 自动剥离 `https://` 前缀、路径与尾点；
  - 自动拆分「多个域名被点号连成一段」的误填（`app.chatwoot.com.cdn.chatwoot.com` → 两个域名）；
  - 剔除非法条目（无点的残 token 等），全部非法时回退默认官方域名（Chatwoot/Crisp）；
- 后台设置页改为**原样提交字符串**由后端解析，并更新中英文提示（分隔符说明、无需协议头、留空用默认）；
- 新增回归测试 5 个：Chatwoot 官方代码 + 默认白名单编译、点号连串+残 token 规范化、空格/分号分隔、协议头剥离、全非法回退默认。

## 升级与使用

- 通过后台「在线更新」或 `git pull && composer install --no-dev` 升级；无数据库变更。
- 已填写白名单的站点：升级后系统会自动规范化现有值；最省事的做法是**清空该字段**（使用默认官方域名），或按 `app.chatwoot.com,client.crisp.chat` 格式填写。
- 改完设置后请强制刷新（Ctrl/Cmd+Shift+R）前台页面再验证客服气泡。
