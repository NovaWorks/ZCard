# v1.9.16

## 🔧 本次更新内容

### 修复:右上角设置按钮无法打开设置面板

**现象**：后台右上角的设置按钮（齿轮图标）点击没有反应，设置面板无法弹出。

**根因**：v1.9.15 菜单布局重构时误删了 `#app-global`（全局组件容器），导致**设置面板 / 水印等全局组件完全未挂载**，设置按钮的 `openSetting` 事件没有监听者。

**修复**：布局容器加回 `<div id="app-global"><ArtGlobalComponent /></div>`，各布局（左侧 / 混合 / 顶栏 / 双列）共用。设置面板、水印等全局组件恢复正常。
