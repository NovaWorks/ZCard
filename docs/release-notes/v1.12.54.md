# v1.12.54

## 🐛 上游库存全显示 -1:同步时补查真实库存(acg-faka 手动发货商品)

**现象**:从 acg-faka 上游拉取 4000+ 商品,库存全部显示 -1(上游站点实际有货)。

**根因**(对照 acg-faka 源码 `app/Controller/Shared/Commodity.php`):
上游 `items` 接口**只有「卡密自动发货」商品(delivery_way=0)才返回 `stock` 字段**;
「手动发货」商品不带 → ZCard 解析为默认 **-1(无限)**。

**修复**(`AcgFakaDriver`):
- `listProducts` 新增 `fetchStock` 参数:
  - **同步模式(队列 Job)传 true**:对 items 无 stock(-1)的商品
    **并发(10)补查真实库存**(`/shared/commodity/stock`,带签名);
    4000 商品在队列内完成,无前端超时。
  - **预览模式(勾选导入)默认 false**:保持快速(实时拉 4000 商品不再额外查库存,
    避免预览超时)。
- 接口 `SupplyDriver::listProducts` 统一加 `fetchStock` 参数
  (dujiao_next/zcard 驱动签名对齐,行为不变)。
- 前端:负数库存显示 ∞(上轮 v1.12.53 已做)。

**效果**:同步后手动发货商品库存为真实数字;0 库存商品被「显示缺货商品」
开关正确隐藏(不再误判为无限)。
