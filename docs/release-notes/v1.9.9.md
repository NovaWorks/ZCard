## 🔧 本次更新内容

### 修复:导入上游商品封面图不显示(相对路径未拼完整 URL)

**现象**：从 acg-faka 等上游勾选导入的商品，前台/后台封面图全部显示为破图。

**根因**：上游接口返回的 `cover` 是**相对路径**（如 `/assets/cache/general/image/xxx.png`），
直接入库后，浏览器按**本站域名**解析该路径（`https://你的域名/assets/cache/...`），
本站根本没有这个路径 → 404 → 图片不显示。

**修复**：商品入库时 `normalizeCover` 归一化封面图 URL——相对路径**拼上上游站点地址**
成为完整 URL（`https://上游域名/assets/cache/...`）；已是 `http(s)://` 完整 URL 的原样保留。
已导入的商品在**下次同步/导入时自动修正**。

## ⬆️ 升级

> 在线更新：后台 → 在线更新 → 检查版本 → 一键更新即可（Git-based）。

```bash
# 手动方式
git pull origin main
php artisan route:clear && php artisan config:clear
```

升级后：
1. 后台「货源对接 → 同步/导入」重新执行一次 → 商品封面图自动修正
2. 浏览器 `Ctrl+F5` 刷新前台/后台

**无数据库迁移。**
