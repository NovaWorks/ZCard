# v1.9.22

## 🔧 本次更新内容

### 1. 修复:/api/currencies 报 "Attempt to read property code on array"

**现象**：前台货币切换器接口 `/api/currencies` 报错，导致前台页面异常。

**根因**：货币缓存改造后 `getEnabledCurrencies()` 返回纯数组集合，但调用方用 `->` 访问模型属性。

**修复**：返回时把缓存数组 hydrate 成模型集合（无 DB 查询，casts 生效），遍历/转换/取货币全部正常。缓存仍存纯数组（database driver 安全）。

### 2. 修复:产品详情页图片不显示

**现象**：商品详情页图片区显示"暂无图片"。

**根因**：上游（acg-faka 等）items 接口只返回封面 `cover`、不返回详情图 `images`，导入后详情图为空。

**修复**：
- 导入时 `normalizeImages`：相对路径拼上游 base_url；**为空时用 cover 兜底**写入 images
- 前端详情图优先 images、为空时**回退 cover**（兼容历史数据）

### 3. 修复:在线更新自动弹出日志不自适应

- 检查更新后自动弹出的更新日志（ElMessageBox）：加 `width: min(720px, 92vw)` 随视口自适应
- 日志框高度撑到视口可用空间，完整展示版本内容
