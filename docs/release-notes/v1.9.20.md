# v1.9.20

## 🔧 本次更新内容

### 1. 产品详情页描述支持 HTML 渲染

商品详情页的描述不再以纯文本输出，支持富文本 HTML 渲染：

- 标题、列表、加粗、图片、链接等富文本正常展示
- 内置富文本排版样式（标题/列表/图片/表格/代码块等）
- **XSS 防护**：自动过滤 `<script>`/`<iframe>`/`<style>` 等危险标签与 `on*` 事件属性

### 2. 在线更新日志高度自适应

- 更新检查页内嵌更新日志框：固定 240px → 视口自适应
- 版本详情弹窗日志：固定 520px → 视口自适应
- 内容少时框小，内容多时撑到视口可用空间后内部滚动，完整展示版本内容

## ⬆️ 升级

> 在线更新：后台 → 在线更新 → 检查版本 → 一键更新即可（Git-based）。

```bash
# 手动方式
git pull origin main
php artisan route:clear && php artisan config:clear
```

**无数据库迁移**，`public/storefront`、`public/admin` 编译产物已随仓库更新。

## 功能清单

- 产品详情页描述 HTML 渲染（含 XSS 过滤）
- 在线更新日志高度随内容自适应
