# v1.12.65

## 🎨 上游商品库存显示口径统一(不再"无限大/无库存"打架)

**反馈**:货源同步后,部分商品前台显示"无限大"(∞),后台显示"无库存/裸数字 -1",两边打架。

**原因**:上游(acg-faka)**手动发货商品没有库存概念**(items 接口不带 stock,
补查接口返回 -1 或无数据),同步后 `stock_cache = -1`。前台把负数渲染成 ∞"无限大",
后台列表把 -1 原样显示成数字,观感为"无库存"。两边口径不一致。

**修复**(显示语义统一,数据层不变):

- **后台商品列表库存列**:
  - `-1` → 绿色标签 **「不限」**(上游不限量/未知,语义准确);
  - `0` → 红色标签 **「缺货」**;
  - `>0` → 真实库存数字。
- **前台商品卡**:
  - `stockText` 负数统一显示 **「不限」**(复用"库存充足"文案),不再显示 ∞"无限大";
  - 0 显示 0,正数显示原数量。
- 后台库存筛选(有货/缺货)原本就按 `stock_cache` 口径判断(-1 视为有货),与显示一致 ✓
- 下单链路对上游商品不做本地库存拦截(由上游兜底),与"不限"语义一致 ✓
