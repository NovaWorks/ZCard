# v1.12.34

## 🐛 修复:支付宝原生支付配置缺失证书参数 + 支持多种支付方式

**现象**:支付宝通道配置后,前端提交支付提示
「配置异常:缺少支付宝配置 -- [app_public_cert_path]」。

**根因**(核对 yansongda/laravel-pay v3 源码 + 参考 dujiao-next/acg-faka):
- yansongda v3 支付宝**强制证书模式**(`StartPlugin` 无条件读取
  `app_public_cert_path` / `alipay_root_cert_path` 计算证书 SN)。
- ZCard `AlipayDriver::buildConfig` 从未传这两个证书字段,且把
  `app_public_cert` / `alipay_public_cert` 都错误地映射为同一个 `public_key`。
- 支付方式仅实现了 `web()`(电脑网站),无当面付/扫码/H5。

**修复**(`app/Payment/Drivers/AlipayDriver.php`):
- **配置补全**:新增 `app_public_cert_path`(应用公钥证书)与
  `alipay_root_cert_path`(支付宝根证书)必填字段;
  两种填法兼容 —— **服务器文件路径** 或 **直接粘贴 PEM 内容**
  (内容自动写入 `storage/app/certs`,按内容 hash 幂等复用)。
- **配置语义修正**:移除错误的 `app_public_cert` / `alipay_public_cert` 混用。
- **支付方式扩展**(通道配置 `pay_type` 选择):
  - `web` 电脑网站支付(HTML 表单)
  - `h5` 手机网站支付(跳转)
  - `scan` 当面付扫码(生成二维码,收银台/支付页展示)
  - `pos` 刷卡支付(付款码)
- **前端**:支付方式展示名补 h5/scan/pos(支付宝图标),新增 qr-scan 图标。

**配置指引**(后台 → 支付设置 → 支付宝通道):
支付宝开放平台 → 密钥管理 → 查看应用公钥证书(appCertPublicKey.crt)与
支付宝根证书(alipayRootCert.crt),粘贴内容或填服务器路径即可。
