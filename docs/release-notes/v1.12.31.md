# v1.12.31

## 🐛 修复:货源商品同步后全部落到「无分类」

**现象**:货源对接点「同步」后,所有商品被同步到前台"无分类"之外。

**根因**(`app/Supply/SupplySyncService.php`):
全量/增量同步时 `resolveCategoryId` 只按「上游分类 code = 本地分类 slug」碰运气匹配,
本地不存在该 slug 分类时返回 `null` → 商品 `category_id` 为空 → 全部归入"无分类"。
(勾选导入有分类映射不受影响;同步流程从不传映射,也不会自动建分类。)

**修复**:
- `resolveCategoryId` 在本地无匹配分类时,**按上游分类自动创建一级分类**
  (slug=上游分类 code, name=上游分类名, 归属主站 merchant 1)。
- 优先级保持:显式分类映射(category_map) > slug 匹配 > 自动创建。
- 幂等:`unique(merchant_id, slug)` + `firstOrCreate`,重复同步不重复建分类。
- 新增 3 个测试:自动创建分类并归入 / 再次同步复用分类 / 显式映射优先于自动创建。

## 验证

- `SupplySyncServiceTest` 7/7(新增 3 用例)。
- 全量 194 通过 / 612 断言。
- 勾选导入行为不变(显式映射优先,已测)。

## 说明

- 修复后重新点「同步」即可:新商品自动进上游分类;已同步到"无分类"的存量商品
  再同步一次会更新 `category_id` 归入自动创建的分类。
