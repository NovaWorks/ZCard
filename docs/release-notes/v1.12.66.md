# v1.12.66

## 💬 右下角在线客服浮窗(issue #7)

**需求**:网站可配置右下角客户服务,支持接入 Chatwoot/Crisp 等第三方客服;
配置的 Telegram / Discord 等客服链接可点击跳转。

### 新功能:客服浮窗

后台「设置 → 在线客服」新增配置项:

| 配置 | 说明 |
|---|---|
| 启用客服浮窗 | 开关,开启后前台右下角显示圆形客服按钮 |
| 浮窗标题(中/英) | 面板头部标题,英文界面自动切换 |
| 客服链接(JSON) | `[{"label":"Telegram","url":"https://t.me/xxx"}]`,支持 http/https/mailto/tel,点击新窗口打开 |
| 第三方客服代码 | 粘贴 **Chatwoot**(Settings → Website → Code)或 **Crisp**(Settings → Websites → Install code)的安装脚本,原样注入前台页面,由其自带气泡渲染 |

前台交互:右下角悬浮按钮 → 点击展开面板(标题 + 客服链接列表),再点关闭。
第三方脚本仅注入一次,不重复加载。

### 增强:页脚客服链接可跳转

页脚「客服联络」中,值为链接( http/https/mailto/tel 开头)时渲染为可点击链接,
不再只是纯文本 —— Telegram / Discord 等配置即可跳转。

### 安全

- 链接经 `safePublicUrl` 清洗(仅 http/https/mailto/tel,`javascript:` 等协议被过滤);
- 第三方脚本仅在站长显式配置时注入。
