# v1.12.41

## ✨ 后台登录页:去掉注册入口 + 支持图形验证码

**需求**:1) 后台登录页去掉「注册」入口;2) 后台开启登录验证码时,
后台登录页也需要输入图形验证码。

### 实现(sysadmin 登录页)

1. **移除「还没有账号?注册」入口**(后台不开放注册)。
2. **新增图形验证码**(`captcha_login` 开启时显示):
   - 登录表单下方显示验证码输入框 + 图片(点击图片刷新)。
   - 提交时携带 captcha;登录失败自动刷新验证码。
   - 验证码图片走现有 `GET /api/captcha/config?scene=login`(session 机制与前台一致)。

### 后端

- 移除 v1.12.40 的「管理端跳过图形验证码」逻辑:后台开启后**前后台一律校验**。
- `X-Client: sysadmin` 头保留(无害),后台登录与前台同口径。

  带正确 captcha → 登录成功 / 前台同样校验 / 关闭时人人可登录。
