# v1.1.7

## 🐛 彻底修复:版本号永远显示 v1.0.0

### 问题

v1.1.6 尝试用读 `.git/refs/tags/` 文件的方式兜底,但部分环境下:
- git clone 时 tag 引用可能未完整下载
- 在线更新(git pull)后缓存未及时刷新
- 各种环境差异导致版本号读取仍不稳定

用户反馈:更新成功后版本号始终显示 v1.0.0。

### 修复:版本号写死在 VERSION 文件

彻底放弃 git 命令和 .git 目录方案,改用**最朴素可靠的方式**:项目根目录的 `VERSION` 文件。

```
VERSION 文件内容:1.1.7
```

`AppHelper::version()` 直接 `file_get_contents('VERSION')`:
- ✅ 纯文件读取,不执行任何命令,不受 `disable_functions` 限制
- ✅ 不依赖 `.git` 目录结构,不依赖 git 命令
- ✅ git pull 时 VERSION 文件随代码更新,版本号自动跟上
- ✅ 容器、宝塔、非 git 部署都能正确显示

**每次发版都会同步更新 VERSION 文件**,这是版本号的唯一真相源。

## ⬆️ 升级

```bash
git pull origin main
chown -R www:www storage bootstrap/cache vendor
rm -f bootstrap/cache/*.php
php artisan optimize:clear
/etc/init.d/php-fpm-84 restart
```

无数据库变更,无前端变更。
