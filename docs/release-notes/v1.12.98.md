# v1.12.98

## 📝 文档：README 的 Node.js 最低版本对齐 sysadmin 实际要求（issue #26）

**报告**：[#26](https://github.com/NovaWorks/ZCard/issues/26) 指出 README 环境要求表写
`Node.js >= 18（可选）`，但 `sysadmin/package.json` 的 `engines.node` 明确要求
`>=20.19.0`——按 README 准备 Node 18 的开发者会进入不受支持的开发环境。

**核实**：属实。且不止 sysadmin 一处：

- `sysadmin`：Vite 7，`package.json` 声明 `engines.node: >=20.19.0`（安装时强制校验）；
- 根目录（storefront 根构建）：Vite 8，Vite 7/8 自身 engines 均为
  `^20.19.0 || >=22.12.0`；
- `storefront/`：Vite 8.1.5（未单独声明 engines，随构建链要求）。

即三处构建链的统一实际口径是 **Node ≥ 20.19**，README 的 `>= 18` 全面偏低。

**修复内容**：

- `README.md` 环境要求表：`Node.js >= 18（可选）` → `>= 20.19（可选）`，说明列补充
  sysadmin 以 `engines.node` 强制校验、根/storefront 同口径；
- 本地 `AGENTS.md`（gitignore，不入库）环境要求同步改为 `Node ≥ 20.19`。

**影响范围**：纯文档修正，代码、依赖、构建产物零改动。生产部署依旧无需 Node.js
（编译产物已入库）；仅影响需要重新编译前端的开发环境。

## 升级与使用

- 通过后台「在线更新」或 `git pull` 升级；无代码变更，仅需重新编译前端时确认
  Node ≥ 20.19（`node -v`）。
