# v1.12.42

## 🐛 修复:后台登录滑块联动开关 + 支付宝错误提示增强 + 超时关单 Cron 配置

### 1. 后台登录滑块与验证码开关联动

后台「关闭登录验证码」时,登录页仍显示滑块(模板硬编码)。
现改为:**滑块与图形验证码统一由 `captcha_login` 开关控制** ——
开启:显示滑块 + 图形验证码;关闭:两者都不显示,直接登录。

### 2. 支付宝当面付错误提示增强(便于定位"不出码")

当面付下单失败时,错误信息补充**支付宝错误码 + 中文提示**:
- `isv.products-not-open-error` → 未开通当面付产品,请到开放平台产品中心开通
- `isv.invalid-signature` / `isv.insufficient-isv-permissions` → 密钥或权限错误
- 其余返回原始 `sub_msg [sub_code]`

> 下单后不出码时,前端会显示具体错误(收银台/支付页红字),
> 把完整报错发来即可精准定位(常见:当面付产品未开通 / 密钥不匹配)。

### 3. 部署指南新增「第 4.5 步:配置计划任务 Cron(必做)」

超时关单/分站解冻/货源自动同步由 Laravel Scheduler 驱动,
依赖服务器每分钟执行 `php artisan schedule:run`。**不配 Cron = 订单永远不会
超时关闭**(后台设置的「订单超时关闭(分钟)」不生效,前台一直"待支付")。
文档已给出 crontab 与宝塔计划任务配置 + 验证命令。
