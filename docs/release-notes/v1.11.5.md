# v1.11.5

## 🐛 修复:composer install 仍报 symfony/yaml 需要 PHP 8.4(dev 依赖遗漏)

**现象**:上一版(v1.11.3/1.11.4)已把生产依赖的 Symfony 组件降到 7.4,但服务器 `composer install`
仍报 `symfony/yaml v8.1.2 requires php >=8.4.1`。

**根因**:`symfony/yaml` 位于 **require-dev 依赖链**中(被 `laravel/sail` 依赖),此前只更新了
`packages`(生产依赖),未处理 `packages-dev`(开发依赖)里的 yaml,导致它仍锁定在 8.1.2。

**修复**:composer.json 的 `require-dev` 中显式约束 `symfony/yaml: ^7.4`,composer.lock 重新解析
(全量含 dev)。

**验证**:
- `packages` + `packages-dev` 全量检查:**无任何包要求 PHP 8.4+**,全部兼容 PHP 8.3
- `symfony/yaml` 已降级至 v7.4.15(PHP 8.2)

## ⚠️ 服务器还需安装 bcmath 扩展

`composer install` 完整执行还需要 PHP **bcmath** 扩展(`yansongda/pay`、`dragon-code/support` 必需)。
请在服务器/Docker 镜像安装:

```bash
# 官方 php 镜像 Dockerfile
RUN docker-php-ext-install bcmath
# 或容器内应急
docker-php-ext-install bcmath
```

## ⬆️ 升级

在线更新:后台 → 在线更新 → 一键更新。更新后:

```bash
composer install   # 前提:bcmath 扩展已装
```
