# v1.12.29

## 🐛 修复:支付成功回跳页一直卡在「支付处理中」

**现象**:支付完成后,支付结果页(PayResult)一直显示
「支付处理中 · 订单 xxx 正在确认」,不会自动显示支付成功。

**根因**:结果页轮询用的是「订单查询」接口(`queryOrders`,按订单号/联系方式查)。
当后台开启「查询密码」(`order_query_password`)且**用户下单时设置了查询密码**时,
该订单会被密码过滤掉(轮询未传密码)→ 永远查不到 → 轮询结束后停在「等待回调」分支。
原轮询仅 5 次(约 7.5 秒),第三方异步回调稍有延迟也会错过。

**修复**(`storefront/src/views/PayResult.vue` + `Pay.vue` 扫码轮询):
- **登录用户优先走「我的订单」(`/orders/mine`,按 user_id 查,不受查询密码过滤)**
  —— 本人支付完必能查到,立即显示支付成功(含卡密)。
- 游客回退订单查询(无密码订单可查)。
- 轮询次数延长:5 次 → **20 次 × 2s(约 40 秒)**,覆盖异步回调延迟。
- 「等待回调」提示补充:若设置了查询密码,请到订单查询页输入密码查看。

**验证**(Playwright 复现用户场景):
开启查询密码 + 下单设置密码 + 余额支付 →
支付结果页**直接显示「支付成功 + 订单号 + 卡密」**,不再卡在支付处理中。
