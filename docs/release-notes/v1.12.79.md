# v1.12.79

## 📋 商品列表:上游价格/成本/加价 + 上游商品链接 + 缺货标识

### 1. 商品列表新增「上游价格/加价」列(上游货源商品)

| 展示 | 说明 |
|---|---|
| **上游售价** | 同步时的上游售价快照(新字段 `upstream_price`,每次同步自动更新) |
| **加价** | 本地售价 - 上游售价(金额 + 百分比,如 ¥1.25 (17%));上游售价缺失时回退成本价 |
| **上游商品链接** | 列内直达上游商品页(acg-faka 自动拼 /buy/{code},可配模板) |

本地商品该列显示「—」。

### 2. 商品编辑抽屉:上游商品链接

编辑上游商品时,「跟随上游调价」开关下方显示**上游商品链接**(可点击),
方便与上游页面核对价格。

### 3. 缺货标识(原有,确认存在)

库存列:上游库存 -1 → 绿色「不限」;0 → 红色「缺货」;正数 → 数量。

### 4. 定时任务同步更新(原有机制)

- 每小时增量 / 每天全量核对 / 改加价比例自动重算 —— 所有同步都会刷新
  `upstream_price` 快照与售价,列表数据与上游实时对齐;
- 任务弹窗的「价格更新 N」统计依然有效。
