# v1.9.11

## 🔧 本次更新内容

### 商品管理:批量设置分类

商品列表新增「设置分类」批量操作，快速整理商品分类：

- 批量操作区新增**「设置分类」按钮**（位于"批量删除"前面）
- 单选或多选商品后点击，弹出**树形分类**选择框（单选）
- 选中目标分类 → 确定 → 选中商品的分类**批量变更**
- 后端 `/api/admin/products/batch` 新增 `set_category` 操作

## ⬆️ 升级

> 在线更新：后台 → 在线更新 → 检查版本 → 一键更新即可（Git-based）。
