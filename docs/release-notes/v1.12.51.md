# v1.12.51

## ⚡ 优化:货源商品预览接口超时与性能

**现象**:客户拉取产品较多时,`/api/admin/supply-sources/{id}/products/preview`
前端 15 秒超时(默认 axios timeout),预览经常失败。

**优化**:
1. **前端**:preview 请求单独放宽到 **120 秒**(axios per-request timeout,
   其余接口仍 15s)。
2. **后端**:预览结果**缓存 60 秒**——
   - 仅缓存成功结果(失败不缓存,上游修复后重试立即生效);
   - 重复点击预览直接命中缓存,不再反复拉取上游全量;
   - **导入成功后自动失效**(`Cache::forget`),已导入标记立即更新。

## 验证

- 后端无迁移。
