# v1.12.10

## 🐛 修复:下单验证码漏传 + 首页分类展示 + 热门标签格式说明

### 1. 下单验证码漏传(老客户"验证码正确仍报错"真正根因)

**根因**:`storefront/src/views/Checkout.vue` 的 `doSubmit()` 里,**单品模式**(`createOrder`)漏传
`captcha` 字段——只有购物车模式(`createBatchOrders`)传了。前端输入了验证码但请求体里没有,
后端 `OrderController::create` 校验 `$data['captcha'] ?? null` → null → 报「验证码错误」。

**修复**:
- `Checkout.vue`:单品模式 `createOrder` 补传 `captcha` + `coupon_code`(与购物车模式对齐)。
- `api/orders.ts`:`createOrder` 类型定义补充 `captcha?`/`coupon_code?` 字段。

**验证**:纯净流程(页面自身验证码 + UI 输入真实答案)提交 → 请求体含 `"captcha":"8075"` →
**201 下单成功**并跳转支付页。

### 2. 首页分类:子分类不可见 + 图标文字错位

**根因**:
- `pills`(顶部横排)模式只渲染一级分类,**无子分类渲染逻辑** → 有子分类的站点子分类看不到。
- Tailwind Preflight 的 `img { display: block }` 使图片图标分类独占一行,按钮被撑到 50px
  (emoji 分类 32px),图标文字垂直错位。

**修复**:
- `CategoryNav.vue`:`pills` 分支复用 `combo` 的子分类下拉面板——点击/悬停有子分类的一级
  分类时弹出子分类胶囊 + 「查看全部」。
- `CategoryNav.vue`:`.cat-icon-img` 加 `display: inline-block` + `vertical-align`。
- `Home.vue`:移动端分类条图片图标加 `inline-block align-middle`。

**验证**:图片图标按钮高度 50px→32px 与 emoji 分类一致;点击含 3 子分类的一级分类,
子分类面板完整显示无裁剪。

### 3. sysadmin 热门标签:格式说明 + 兼容逗号分隔

**根因**:placeholder 写"多个标签用英文逗号分隔,如:优惠,新品,热销"(文字标签),但实际格式是
**JSON 分类 ID 数组**(`parseArr` 用 `JSON.parse`)——提示与实现矛盾,照提示填必然报
「JSON 格式错误」。

**修复**:
- placeholder 改为「JSON 数组格式,填入分类 ID,如: [1, 3, 5]」。
- **右侧新增格式说明**:「格式:分类 ID 数组(JSON)…」「示例:[2, 5, 8] → 展示 id 为 2、5、8 的分类名」。
- `parseArr` **兼容逗号分隔输入**(`8,9` → `[8, 9]`),老用户习惯不受影响。

**验证**:JSON 格式 `[8, 9]` 与逗号格式 `8,9` 均保存成功,后端存储 `[8, 9]`。
