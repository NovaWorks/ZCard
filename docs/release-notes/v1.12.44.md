# v1.12.44

## 🐛 修复:当面付二维码 canvas 空白(渲染时机问题)

**现象**:URL 已正确带 `order_no` + `qrcode`,但结果页二维码区域只有空的
`<canvas>`,没有绘制内容。

**根因**:v1.12.43 中 `renderQrcode()` 在 `loading.value = false` 后**立即**调用,
而二维码 canvas 位于 `v-else-if` 分支 —— Vue 重渲染是异步的,
此刻 `qrCanvas` ref 仍为 `null` → 函数直接 `return`,从未绘制。

**修复**(`storefront/src/views/PayResult.vue`):
- 改用 `watch(qrcodeContent, ..., { immediate: true })` 触发渲染,
  内部 `await nextTick()` **等 canvas 挂载完成后再绘制**。
- 从 onMounted 移除直接调用(避免同样时序问题)。

- 后端无改动。
