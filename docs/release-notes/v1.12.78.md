# v1.12.78

## 🧮 修改加价比例 → 立即自动重算商品售价 + 任务统计

### 客户反馈还原
- 加价比例从 150% 改成 600%,商品售价**没有变化**(仍按旧比例算出的价格);
- 检查确认:**公式无误**(150% → ×2.5,600% → ×7),问题是修改加价比例后
  要等每小时定时同步才生效 —— 期间商品价格停留在旧比例的结果。

### 修复:保存加价设置 → 立即派发全量同步(自动重算)

- **编辑货源**保存时,若定价设置(`default_pricing_mode` / `default_markup_percent`
  / `default_markup_amount`)发生变化 → **自动派发一次全量同步任务**;
- 全量同步按新加价规则重算所有**未手动改价**商品的售价(改价保护不受影响),
  并统计 **价格更新成功数**;
- 已有同步进行中时自动跳过(不重复排队,定时/手动同步会覆盖);
- 无需再等每小时定时任务,保存即生效。

### 任务弹窗:价格更新统计展示

- 单货源任务卡片与全部任务列表均新增 **「价格更新 N」**(橙色高亮):
  本次同步中售价实际变化的商品数;
- 配合已有「已处理/总数」进度,可直观看到"修改价格成功 X / 总数量 Y"。

### 定时器兜底(原有)
- 每小时增量同步 + 每天全量核对:即使忘记手动操作,上游调价/加价设置变更
  也会在定时任务中自动落库。

## 验证

- 新增 2 个测试(改加价比例自动派发全量任务 / 改无关设置不触发),全量 **290 通过 / 932 断言**;
- sysadmin 构建通过,产物已重建;
- 无数据库迁移。
