# v1.11.0

## ✨ 新功能:前台商品列表分页

首页「全部商品」与各分类商品列表不再只显示第 1 页,新增「加载更多」按钮分页加载:

- 每次加载一页(页大小可在后台「店铺设置 → 商品展示 → 每页数量」配置)
- 点击「加载更多」追加下一页商品,加载完自动隐藏按钮
- 底部显示当前页码/总页数

## 🧹 优化:移除后台无效的快速入口卡片

后台顶部「快捷入口」面板中的**快速链接**区域已移除(原包含登录/注册/忘记密码/定价/个人中心/留言管理 6 个无效卡片,
这些是前台页面路由,后台点击无意义)。

## 🐛 修复:定价策略加价百分比上限

货源管理「拉取商品 → 定价策略」与「货源设置」中的百分比加价,原上限 500%(无法输入更高),
已移除上限,可设置任意加价百分比。

## 💡 说明:商品视图切换(网格/列表/双栏)

接到反馈「后台设置默认视图点击切换无效」,已核实:

- 后台「店铺设置 → 商品展示 → 默认视图」的网格/列表/双栏切换功能正常
- 前台首页右上角 ⊞/☰/▦ 切换按钮功能正常,且保存后台默认视图后前台默认生效
- 若遇到切换无反应,请**强制刷新浏览器**(Windows: Ctrl+F5,Mac: Cmd+Shift+R)清除旧版缓存

## ⬆️ 升级

在线更新:后台 → 在线更新 → 一键更新。**无数据库迁移**。
`public/admin`、`public/storefront` 编译产物已随仓库更新。
