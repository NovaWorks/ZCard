# v1.12.7

## 🐛 修复:充值支付页只显示通道名,未展示具体支付方式

### 问题
充值支付页(RechargePay.vue)直接显示通道名(如「易支付」),
但收银台(Checkout.vue)会按 `pay_types` 展开具体支付方式(支付宝/微信等)并显示图标+名称。
客户站 kmigo.com 易支付通道配置了 `pay_types=['alipay','wxpay']`,
但充值页只显示「易支付」,用户看不到支付宝/微信。

### 修复
RechargePay.vue 复用收银台逻辑:
- 新增 `PAY_TYPE_META`(支付方式标识→图标/名称)与 `channelPayTypes()`(按 pay_types 展开,无则回退通道本身)
- 模板按 pay_types 展示图标 + 名称连接(如「支付宝 / 微信支付」),与收银台一致

## ✅ 验证
- storefront typecheck + build 通过。
- 与收银台 Checkout.vue 的 `PAY_TYPE_META`/`channelPayTypes` 逻辑完全一致。
