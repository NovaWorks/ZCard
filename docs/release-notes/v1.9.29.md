# v1.9.29

## 🐛 修复:底部信息栏固定显示且不再遮挡内容

**现象**：v1.9.28 新增的底部 GitHub/群组信息栏，滚动后消失（sticky 在 flex 布局中失效悬空）；
改为 fixed 固定后，又遮挡了工作台「运营告警/支付通道」等页面底部内容。

**修复**：
- 后台底部栏改为 `position: fixed` 固定在视口底部（任何页面、任何滚动位置始终显示）
- 内容区预留底部空间（两种布局的 `#app-content` 增加 `padding-bottom`），滚动到底时内容不再被底部栏遮挡
- 工作台（dashboard）内容超出固定高度时改为**内部滚动**，卡片不会被固定栏盖住

**验证**（Playwright 实测）：
- 工作台滚动到底：所有卡片底部 ≤ 底部栏顶部，无重叠
- 商品列表滚动到底：页面内容底部 1025 < 底部栏顶部 1042，无遮挡
- 前台页脚版权栏（sticky bottom）不受影响，仍正常固定
