# v1.12.87

## 🐛 修复：后台订单详情看不到已发货卡密（含上游拿货卡密）

**客户反馈**：顾客购买上游货源商品（如 acg-faka 对接）付款发货后，管理员在后台订单详情中看不到上游卡密内容。

**根因**：v1.12.85 安全整改中为 `OrderDelivery` 模型增加了 `$hidden = ['card_content']`（防止模型序列化时误泄露卡密），但 `GET /api/admin/orders/{id}` 依赖 `$order->toArray()` 序列化发货记录，卡密字段被一并隐藏 → 后台详情接口不再返回发货内容（本地卡密同样受影响）。

**修复内容**：

- `Admin/OrderController::show` 改为显式映射 `deliveries` 数组并**回填卡密明文**——该端点由 `admin.role`（仅超管）+ `audit.admin`（操作审计）双重守卫，是管理员核对发货内容的正式入口，卡密可见性是设计内行为；
- `OrderDelivery::$hidden` 保持不变：其他不经管理员守卫的序列化路径依旧不会外泄卡密（纵深防御不降级）；
- 新增回归测试 `AdminOrderDetailTest`：
  - 超管访问订单详情 → `deliveries[].card_content` 完整返回（多张卡密逐条可见）；
  - 未认证 → 401、普通登录用户 → 403，响应不含卡密。

## 升级与使用

- 通过后台「在线更新」或 `git pull && composer install --no-dev` 升级；无数据库变更。
- 升级后重新打开订单详情即可看到上游/本地发货卡密；历史订单同样生效（数据一直完整保留在 `order_deliveries` 表）。
