# v1.11.7

## 🐛 修复:后台顶栏版本号更新后仍显示旧版本

**现象**:在线更新到新版本后,后台顶栏版本徽章仍显示旧版本号(如更新到 v1.11.6 仍显示 v1.11.5),刷新不生效。

**根因**:顶栏版本徽章调用 `/api/admin/update/check` 接口获取 `current_version`,该接口内部使用
`AppHelper::version()` —— 它用 `Cache::remember` 缓存版本号 **5 分钟**(缓存后端为 database)。
更新完成后虽然 `UpdateController` 已调用 `clearVersionCache()`,但:
1. 缓存窗口期内(5 分钟)顶栏 check 可能读到更新前缓存的旧值
2. 更新进程清缓存与前端请求读缓存之间存在竞态,导致用户看到旧版本

**修复**:
1. `AppHelper::version()` 缓存时间从 **300 秒缩短到 60 秒**(版本号读取频繁但内容极少变,60 秒足够)
2. `/api/admin/update/check` 接口每次调用**先清版本缓存再读取**,保证顶栏刷新必定显示最新版本号
   (check 是低频调用,顶栏加载时一次,无性能问题)

**效果**:更新完成后刷新后台,顶栏版本徽章立即显示新版本号,无需等待缓存过期。

## ⬆️ 升级

在线更新:后台 → 在线更新 → 一键更新。**无数据库迁移**。
更新后刷新页面,顶栏版本徽章即显示 v1.11.7。
