# v1.9.31

## ✨ 本次更新内容

### 1. 新增:购物车 + 收银台(大功能)

**购物车**
- 商品详情页新增「加入购物车」按钮(原为占位符),「立即购买」直达收银台
- 顶部导航新增 🛒 购物车入口(数量角标,移动端菜单同步),购物车数据本地持久化

**收银台**(参考大厂双栏布局)
- 左侧:商品明细卡片(图/名称/SKU/单价/数量步进器/小计/移除),支持多商品
- 右侧(吸顶):联系方式+查询密码+验证码 → 优惠券输入 → 支付渠道单选(图标+币种) → 合计/优惠/应付 → 提交按钮(显示应付金额)
- 提交后自动创建支付并跳转支付链接,成功后清空购物车

**后端聚合支付**
- `POST /api/orders/batch`:购物车多商品事务下单(每商品一单,库存不足整体回滚;优惠券自动作用于第一个适用商品,同时放宽了优惠券的多数量限制)
- `POST /api/payments/batch-create`:一次支付多个订单(新增 `payments.order_ids` 字段,金额为各订单之和,回调统一发货)
- 支付回调支持对多个订单统一标记支付成功(幂等)

### 2. 修复:在线更新页更新日志换行不识别

GitHub Release 说明中误存为字面量 `\n` 的换行无法渲染。已修复:渲染前将字面 `\n` 规范化为真实换行,更新日志正确分行显示(列表/段落)。

## ⬆️ 升级

在线更新:后台 → 在线更新 → 一键更新即可(Git-based)。

**需要执行数据库迁移**(新增 `payments.order_ids` 字段,一键更新会自动执行)。
