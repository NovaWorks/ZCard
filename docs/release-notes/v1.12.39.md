# v1.12.39

## 📖 部署指南更新:按代码实际重写「禁用函数」说明 + 新增图片/支付排查

**背景**:客户反馈很多人在「图片」一步卡住需要解除禁用函数。
原文档禁用函数表过于简略,且未覆盖宝塔「安全防护」插件禁 `curl_exec` 的场景。

**本次更新**(`docs/部署安装指南.md`,基于代码实际依赖逐项核对):

1. **禁用函数表重写** — 按影响功能分组并标注必需级别:
   - `putenv`(必需):Laravel 读 .env / Composer / 队列
   - `curl_exec` / `curl_multi_exec`(**必需,新增**):支付发起(支付宝原生驱动)、
     货源对接(上游 HTTP)、易支付/聚合支付、远程图片 —— 被安全插件禁用时
     「发起支付报错 / 上游拿不到货 / 回调不生效」
   - `proc_open` / `shell_exec` 等:后台「在线更新」(UpdateController 执行 git/composer)
   - 明确说明:**图片上传/验证码依赖的是 PHP 扩展 `gd` + `fileinfo`(非禁用函数)**
2. **新增「问题 14:图片上传失败 / 验证码不显示 / 发起支付报错」FAQ** —
   现象 → 原因(缺扩展 gd/fileinfo、curl_exec 被禁、putenv/proc_open 被禁)→
   排查命令(`php -m` 确认扩展、`function_exists` 确认函数)→ 解决步骤。
   附「区分口诀」:图片/验证码先查扩展,支付/货源/远程先查禁用函数。
3. **错误速查表**补 3 行(gd 缺失 / curl_exec 被禁 / 上传失败指引)。
4. 目录同步。
