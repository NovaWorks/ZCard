# v1.12.3

## 🛠 在线更新自愈:git "dubious ownership" 不再阻塞更新

**问题**:宝塔环境下 `.git` 属主为 root,PHP-FPM 以 www 运行。git 的安全机制
("dubious ownership") 会拒绝任何 git 操作,导致后台在线更新卡死在 `git fetch` 一步。

原代码虽然调用了 `ensureGitSafeDirectory()`(通过 `git config --global --add safe.directory`
写入白名单),但该写入依赖 PHP-FPM 的 `$HOME/.gitconfig` **可写**——宝塔的 PHP-FPM
HOME 常不可写或未设置,写入静默失败,白名单根本没生效,后续 git 命令依然被拒。

**修复**:所有 git 操作改为**内联配置** `git -c safe.directory=<项目路径> ...`,
在每次调用的命令行里直接声明安全目录,**不依赖任何配置文件**。
即使 `git config --global` 写入失败,`git fetch/reset/status/clean/checkout/remote`
也能正常执行。

涉及更新与回退两条链路的所有 git 调用:
`fetch + reset`(更新)、`reset --hard HEAD~1`(回退)、`status --porcelain`(备份检测)、
`reset --hard HEAD`(清理工作区)、`clean -fd`(清未跟踪)、`remote get-url/set-url`(HTTPS 切换)、
`checkout HEAD`(前端产物校验)。

## ✅ 验证

- `php -l` 语法通过;仓库无 UpdateController 测试(涉及真实 git 文件系统,属已知缺口)。
- 本次改动为纯命令构造层修复,不影响任何业务逻辑。
