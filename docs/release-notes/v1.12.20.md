# v1.12.20

## 🐛 修复:公告弹窗首次访问不弹出

### 根因

`NoticeModal` 用 `onMounted` 判断是否弹出,但此时 `settings.config` **尚未加载完成**
(settings 是异步 `getStorefrontSettings()` 拉取,`onMounted` 执行时 config 仍为 null)
→ `noticeHtml` 为空 → 弹窗不弹出。首次访问必现(之前本地测试能弹是因为页面已预热过 settings)。

### 修复

`onMounted` 改为 `watch(noticeHtml, ..., { immediate: true })`:settings 异步加载完成后
**自动响应触发弹窗**。

### 验证(真实首次访问场景)

| 场景 | 结果 |
|---|---|
| 全新访客首次访问(清空 localStorage,不预热) | 弹窗弹出 ✓ |
| 点击「我知道了」关闭 | 消失 + `zcard_notice_dismissed=1` ✓ |
| 刷新(会话内) | 不再弹 ✓ |
| 清除标记后再访问 | 重新弹出 ✓ |
