# v1.12.53

## ✨ 新增:商品展示开关——「显示缺货商品」(后台可配,默认开启)

**需求**:店铺设置 → 商品展示 新增开关,默认开启;关闭后前台库存为 0 的商品不显示。

**实现**:
- **后端** `StorefrontConfig` 新增 `show_out_of_stock`(默认 true)。
- **后台**(店铺设置 → 商品展示)新增「显示缺货商品」开关(中英双语说明)。
- **前台过滤**(`ProductController::index` / `featured`):
  - 关闭时,商品列表与首页推荐**不展示缺货商品**;
  - 本地商品:无未使用卡密 → 缺货,隐藏;
  - 上游商品:`stock_cache = 0` → 缺货,隐藏;`-1`(无限)与未知(null)始终显示;
  - 商品详情页直接访问不受影响(仅列表/推荐隐藏)。

## 验证

- `tests/Feature/ShowOutOfStockTest`(4 用例):开关关→本地缺货隐藏/有货显示;
  开关开→缺货显示;上游 0 库存隐藏且 -1 无限显示;推荐同样过滤。
