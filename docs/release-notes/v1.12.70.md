### 2. 异常登录监控与告警

- **登录审计**:登录成功/失败均记录 IP/UA 到安全审计日志;
- **陌生登录检测**:超级管理员从**从未用过的 IP 或新设备(UA 指纹)**登录时触发告警;
  首次登录只建立基线不告警,常用 IP+设备不打扰;
- **告警渠道**(后台「系统」→ 登录安全告警,配置非空即启用):
  - 邮件(SMTP 复用现有配置);
  - **Telegram Bot**(Token + Chat ID);
  - **企业微信机器人 Webhook**(个人微信无法直连,企微群机器人是标准方案);
- **异步发送**,失败静默不影响登录;总开关可一键关闭。
