# v1.12.43

## 🐛 修复:支付宝当面付扫码不出二维码,结果页一直"支付处理中"

**现象**:当面付选「生成二维码」下单后,跳转到 `pay/result?order_no=&qrcode=...`,
页面只显示「支付处理中,请稍后查询」,**不展示二维码**。

**根因**(两个 bug):
1. **Checkout 跳转丢订单号**:qrcode 场景 `router.push({ order_no: '', qrcode: ... })`
   ——订单号传空,PayResult 无单号可轮询。
2. **PayResult 不渲染 qrcode 参数**:结果页只处理订单号轮询,
   从未展示过二维码内容。

**修复**:
- **Checkout.vue**:qrcode 跳转带上订单号(单品/购物车都传)。
- **PayResult.vue**:
  - 新增 `qrcode` 参数处理:使用 `qrcode` npm 包在 **canvas 渲染二维码**
    (支付宝当面付扫码页面)。
  - 展示二维码的同时**带订单号轮询支付状态**,用户扫码支付成功后
    自动切换到「支付成功 + 卡密」页。
  - 中英双语文案(扫码支付/请用支付宝 App 扫码…)。

## 验证

- 后端无改动。
