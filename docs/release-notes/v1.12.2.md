# v1.12.2

## 🐛 修复:多货币显示与下单快照

### 1. 切换货币后金额不换算(符号变但金额不变)

**根因**:后台未启用目标货币(只设了汇率没勾选「启用」)时,后端 `ResolveDisplayCurrency`
中间件会把 `X-Currency: USD` 回退到基础货币 CNY,`price_display` 返回 CNY 分;
但前端所有金额用「用户选择的货币符号」格式化,导致出现 **$ + 人民币金额** 的错乱展示。

**修复**(前端):
- 商品价格 / 订单金额展示:符号**跟随后端返回的 `display_currency`**(`prefs.currencyOf`),
  保证符号与金额永远一致。涉及:首页商品卡、详情页、收银台、订单查询/我的订单/支付结果/个人中心。
- 账户类金额(余额 / 佣金 / 账单 / 充值 / 提现 / 分站财务):固定用**基础货币**展示
  (`prefs.baseCurrencyInfo`),不随显示货币漂移——账户以基础货币记账,避免财务金额误导。

### 2. 下单金额快照货币错误

**根因**:`OrderController::create/batch` 的 `display_currency` 只从**请求体**读取,
但前端下单时**并不传**该字段 → 订单快照的 `display_currency`/`amount_display`/`exchange_rate`
恒为基础货币,即使客户界面用的是 USD。

**修复**:快照货币优先取 `request->attributes->get('currency')`(中间件已按 X-Currency 解析),
请求体字段作兜底。订单 `amount` 仍始终为基础货币分(记账真相源),回调核对口径不变。
