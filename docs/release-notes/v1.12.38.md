# v1.12.38

## ♻️ 支付宝重构:放弃 yansongda 证书模式,改为原生「公钥模式」(参考 dujiao-next)

**客户反馈**:支付宝对接太复杂。证书模式(应用公钥证书/支付宝根证书/SN)配置繁琐,
且出现「少支付宝公钥证书输入框 → 能出链接不出二维码 → 出二维码回调不验签」等问题。

**决策**:两代 dujiao 均为「加签方式=密钥」——只需 **应用 APPID + 应用私钥 + 支付宝公钥**
三项即可。本次将 `AlipayDriver` 重写为**原生 RSA2 公钥模式**(不再依赖 yansongda 证书链路):

- **下单签名**:公共参数 + biz_content → 剔除空值与 sign → ksort → `k=v&` → RSA2(SHA256)→ base64
- **当面付扫码** `alipay.trade.precreate`:POST 网关解析 `qr_code` → 前端出二维码 ✅
- **电脑网站** `alipay.trade.page.pay` / **H5** `alipay.trade.wap.pay`:自动提交表单跳转
- **刷卡支付** `alipay.trade.pay`:付款码
- **回调验签**:剔除 sign/sign_type 与空值 → ksort → `k=v&` → 支付宝公钥 `openssl_verify` ✅
- 私钥/公钥兼容带/不带 PEM 头、PKCS8/PKCS1
- 回调金额 `total_amount`(元)→ 分,与支付流水核对口径一致

**配置大幅简化**(后台 → 支付设置 → 支付宝通道,仅 3 项必填):

| 字段 | 必填 | 来源 |
|---|---|---|
| 应用 APPID | ✅ | 开放平台应用详情 |
| 应用私钥 | ✅ | 密钥管理 → 应用私钥(复制内容,带或不带 PEM 头均可) |
| 支付宝公钥 | ✅ | 密钥管理 → 支付宝公钥(复制内容) |
| 支付方式 | 选「当面付扫码/电脑网站/H5」 | 对应产品需在开放平台开通 |

> 旧证书/SN 配置字段已移除;如之前配置过证书,重新填入上述 3 项即可。
