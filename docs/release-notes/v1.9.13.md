# v1.9.13

## 🔧 本次更新内容

### 1. 拉取商品:分类映射(上游分类 → 本地分类)

「货源管理 → 拉取上游商品（勾选导入）」弹窗新增**分类映射**面板：

- 每个上游分类可选择导入到**本地已创建的分类**（树形、可搜索），导入时直接写入 `category_id`，无需逐个编辑
- 没有合适分类时可**按上游分类名一键创建**同名本地分类并自动映射（幂等，同名跳过）
- 行内「创建」按钮支持单个分类手动创建
- 未映射的分类沿用原逻辑（按上游分类 code 自动匹配本地，匹配不到留空）

### 2. 拉取商品:已对接 / 新货源标识

上游补货时一眼区分对接状态：

- **已对接**（已导入本地）：绿色「已对接」标签 + 浅绿行底色（弱化）
- **新货源**（未导入）：蓝色「新货源」标签（突出）
- 顶部汇总显示「已对接 N 个」
