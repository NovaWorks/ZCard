# v1.12.93

## 🐛 修复：客服域名白名单在 PHP 8.3 下触发变长 lookbehind 编译失败（issue #14）

**报告**：[#14](https://github.com/NovaWorks/ZCard/issues/14) 指出 v1.12.92 中 `ServiceWidgetScript::normalizeHosts()` 的点号连串拆分使用了变长 lookbehind 正则：

```php
preg_split('/(?<=\.(?:com|net|org|io|chat|app))\./', $entry)
```

**核实**：属实。PCRE2 < 10.43（PHP 8.3 及以下）不支持变长 lookbehind，该表达式**无法编译**——
只要 `service_widget_allowed_hosts` 非空，`GET /api/settings/storefront`、`GET /api/settings/service-widget-script`、
`PUT /api/admin/settings` 即 500。本地开发（PHP 8.5 / PCRE2 10.43+）与部分线上（更新版 PCRE2）可编译，
因此此前测试与 kmigo.com 未暴露此问题——版本相关性确认成立。

**修复内容**：

- 拆分逻辑改为捕获组替换再拆分（不依赖 lookbehind，全版本可编译，语义一致）：

  ```php
  $splitEntry = preg_replace('/\.(com|net|org|io|chat|app)\./', '.$1,', $entry);
  $blocks = $splitEntry === null ? [$entry] : explode(',', $splitEntry);
  ```

- 已对 6 组边界输入（含 `chat.example.com`、`app.chatwoot.com.cdn.chatwoot.com`、`a.chat.example.com` 等）
  做新旧实现对比，拆分结果完全一致；
- 新增回归测试 `test_dot_joined_host_split_is_compatible_with_pcre2_10_42`；
- 部署指南补充 Nginx 两个常见坑：① `/api/` 被静态规则吞掉返回 404；② CSP 头较大触发
  `upstream sent too big header`（FastCGI 首缓冲 4KB 默认值，建议 `fastcgi_buffer_size 16k` 等）。

## 升级与使用

- 通过后台「在线更新」或 `git pull && composer install --no-dev` 升级；无数据库变更。
- PHP 8.3 环境升级后即可正常配置客服白名单；无需改动现有配置。
