# v1.12.73

## 🗂️ 货源「查看任务」入口 + 队列状态检测

### 1. 查看任务按钮
货源管理工具栏「新增货源」旁新增 **「查看任务」** 按钮:
- 弹窗展示**全部货源**的同步任务(最近 50 条):货源名、状态标签
  (排队中/同步中/已完成/失败/已取消)、进度条、新增/更新计数、完成时间、错误信息;
- 进行中任务 5 秒自动刷新。

### 2. 队列状态检测(弹窗顶部横幅)
- 打开弹窗自动**派发队列探针**(轻量 Job),worker 正常时心跳立即刷新;
- **绿色横幅**:「队列运行正常,任务将自动后台执行」;
- **红色横幅**:「队列未开启:同步任务不会执行」——附开启指引:
  宝塔(进程守护管理器)/ systemd,执行命令 `php artisan queue:work`,
  并提示启动后回到页面会自动转绿、历史任务可重新同步;
- 检测结果 5 秒轮询刷新(worker 启动后自动恢复绿色,无需刷新页面)。

### 技术实现
- 探针 Job `QueueHeartbeatJob` 写缓存心跳,`queue-status` 接口判定
  20 秒内是否活跃(兼容 database/redis/file 队列,测试环境 sync 立即通过);
- 静态路由 `supply-sources/sync-tasks` 等注册在 apiResource **之前**
  (遵守项目路由顺序规则,避免被 `{supplySource}` 参数吞掉)。
