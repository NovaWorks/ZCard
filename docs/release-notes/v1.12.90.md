# v1.12.90

## 🔒 本次更新内容

> 本版为**安全加固大版本**：完成全量安全审计整改(8 项高危 + 12 项中危 + 20 项低危),
> 同时包含上一批已发布的「供货账号审核制」与「客服脚本修复」。**共 378 项自动化测试全绿。**

### 高危修复(H)

- **H-1 下单约束服务端强制**：下架/隐藏商品、仅会员商品(游客)、最小/最大起购量、
  限购数量(按已支付+待支付累计)、禁用/跨商品 SKU——此前全部只在前端过滤,直接调 API
  可绕过;现在 `OrderService::createOrder` 服务端逐一校验,下架/隐藏与"不存在"同响应(404)。
- **H-2 供货账号审核制**:自助开通默认待审核,管理员审核通过前无法调用供货 API;
  后台「供货账号管理」支持一键审核/撤销;设置页新增「自助供货自动审核」开关
  (开启即注册享供货价);存量与管理员创建账号默认已审核,升级不中断对接。
- **H-3 支付驱动凭据键自声明**:回调前"凭据已配置"门禁改由各驱动 `getCredentialKeys()`
  自声明——修复 OkPay(merchant_token)/TokenPay(notify_secret)凭据已配置却被误判
  「未配置」导致**收款不发货**的严重问题。
- **H-4 USDT 静态 API Key 回退移除**:该模式 key 可经 GET 明文进日志、无时间戳/nonce
  可重放,泄露即可对任意 pending 订单伪造回调免费拿货;现在仅支持 HMAC-SHA256 回调
  (存量静态 key 监听器需升级配置 secret_key)。
- **H-5 在线更新通道加固**:update/rollback 执行前强制**管理员密码二次确认**;
  回滚禁止退到安全基线 v1.12.85 以下(防降级攻击)且限 3 次;fetch 前校验 git remote
  与官方仓库一致(防 .git 被篡改后借"合法更新"部署恶意代码);array 缓存驱动下原子锁
  失效直接拒绝执行。后台更新/回退按钮已配合增加密码确认弹窗。
- **H-6 后台新建用户余额走流水**:store 路径不再直写 balance(v1.12.88 只修了 update),
  初始余额经 `BillService` 生成账单(含操作管理员,可对账)。
- **H-7 会话认证 CSRF 补缺**:新增 `VerifyCsrfForSessionAuth` 中间件——携带会话 Cookie
  的写请求若来源(Origin/Referer)不在第一方域名内,必须携带有效 CSRF token;
  `SESSION_SAME_SITE` 硬编码 lax(禁止 env 改 none);分站同域场景不再可跨站代操作。
- **H-8 慢支付通道关单宽限**:USDT 类通道存在未结支付流水且在宽限期内(默认 60 分钟,
  可配 `slow_channel_close_grace_minutes`)的订单不自动关单——修复「链上到账时订单已关、
  卡已释放,付款成功永不发货」的资损场景。

### 中危修复(M)

- **M-1** 后台"清理无用订单"先走正常关单流程(释放锁定卡密 + 回滚已核销优惠券)再删除,
  不再产生永久锁死的孤儿卡与不可自愈的库存损耗。
- **M-2** 卡密 unlock 同时解除订单绑定;锁定中的卡不可直接禁用;发货只取「本单绑定的
  锁定卡」且数量不足时显式报错——修复扣款后卡单/发禁用卡。
- **M-3** 分销佣金、管理员调账不再计入"累计充值"——只有真实充值计,堵住小号自购返佣
  折价刷会员等级的套利;佣金层级环(pid 成环)同一人只发一份;管理端改 pid 增加祖先链
  环检测。
- **M-4** 供货 API 组按 IP 前置限流(60/分钟)——修复鉴权失败路径无限流可被未认证请求
  打成 DB 放大器;`supply_supplier_enabled`(作为上游供货)开关真正生效(此前无代码消费)。
- **M-5** 供货订单取消为真实取消:事务内关闭本地订单、释放锁定卡、退款入账并写退款
  流水(幂等);已发货订单返回 409。此前返回成功但什么都不做,下游余额被静默占用。
- **M-6** 安装向导默认**仅允许本机**(回环)访问安装接口,公网安装需在 .env 配置
  `ZCARD_INSTALL_ALLOWED_IPS`(防未装实例被公网抢装);安装完成自动写入
  `APP_ENV=production / APP_DEBUG=false / LOG_LEVEL=error`(修复 .env.example 默认
  local+debug 被照抄进生产);HTTPS 安装自动开启 `SESSION_SECURE_COOKIE`;
  run() 与 test-db 同口径拒绝内网 DB 地址(Docker/内网部署配
  `ZCARD_INSTALL_ALLOW_PRIVATE_DB=true` 豁免);status 端点不再回显 PHP 精确版本。
- **M-7** Filament 登录页接入账号级失败锁定(同账号 5 次锁 15 分钟,与 API 登录共享
  锁定状态)——此前只有每 IP 限流,IP 池可爆破管理员密码。
- **M-8** 发布 `config/cors.php`:默认不放开任何跨域来源(此前落回框架默认 `*` 全开);
  分站/独立前端需跨域调 API 时配置 `CORS_ALLOWED_ORIGINS`。
- **M-9** 卡密加密默认开启(密钥已生成时):新卡密加密入库,存量明文卡自动识别并正常
  发货(密文形态识别);发货链路解密失败(密钥变更/损坏)阻断并告警,不再把密文当卡密
  发给买家。
- **M-10** 在线更新修复 `.git` 目录权限不再对其他用户放开读写(原 `go+rwX` 允许共享
  主机本地用户改写 .git/config 注入命令提权)。
- **M-11** 支付回调端点(callback/notify)加 60 次/分钟限流;PayPal 驱动单号格式白名单
  + access token 缓存(防匿名请求打满商户 API 配额导致真实买家支付确认失败)。
- **M-12** 登录/注册成功后重建会话 ID(防会话固定);修改密码/管理员重置/禁用/改权
  同时吊销全部会话与令牌(被盗 Cookie 一并失效)。

### 低危/加固(L,摘要)

- 下单接口:数量边界、SKU 归属与启用状态服务端校验;查单密码锁定键改为按关键字
  (不含 IP,防代理池重置计数)。
- 供货 HMAC 签名串新增 query md5 段(双口径兼容升级,防中间人改写查询参数);
  Dujiao 上游回调补防重放;上游 base_url 保存时校验必须解析公网 IP(纵深防 SSRF);
  nonce 数据库后端改存 sha256 摘要(修复列溢出/前缀互撞)且仅唯一冲突视为重放;
  供货查单 404/401 统一消除订单号枚举;未发货供货订单不再回传卡密;上游回调单号
  与本地登记一致性校验。
- 支付:支付宝回调核对 app_id;同单同通道重复发起支付旧流水标记 superseded(防按旧
  金额付款被误判金额不符);OkPay/TokenPay 回调地址改用安全 URL 生成器(防 Host 头
  污染);微信支付显式传 notify_url;回调失败响应统一为 fail(消除配置探测 oracle)。
- 后台:卡密列表短卡密预览打码;订单列表/详情不再回传查询密码与访问凭证哈希;
  卡密导入限制 1MB 且错误日志不再落整行明文;找回密码在注册或登录验证码任一开启时
  要求验证码;登录失败时序拉平(防用户名枚举);User 模型 balance 等资金字段移出
  批量赋值白名单。
- CSP:WebSocket 出口收敛为客服白名单主机(原裸 `wss:` 允许连任意 WS 服务器外发数据)。

### 新增:供货账号审核制(安全审计 H-2)

详见上文 H-2;含「注册即享供货价」开关与前台待审核提示。

### 修复:后台填写客服代码后前台不显示

- 根因:非白名单域名的脚本被安全策略整段丢弃,但 `script_configured` 仅判断脚本非空,
  前台进入原生模式加载空 JS 且隐藏兜底链接浮窗 → 两种客服都不显示。
- 修复:`script_configured` 改按编译结果判定(被丢弃时前台自动回退链接浮窗);
  后台保存时检测并弹警示,提示把代码引用的域名加入「受信域名白名单」。

## ⬆️ 升级

> 在线更新:后台 → 在线更新 → 检查版本 → 一键更新(需输入管理员密码二次确认)。

```bash
# 手动方式
git pull origin main
php artisan migrate && php artisan route:clear && php artisan config:clear
```

**必读升级说明**:

1. 本次包含数据库迁移(`supplier_accounts.approved` + `user_id` 唯一索引),**必须执行
   `php artisan migrate`**;
2. **USDT 通道**:若你在用旧版"静态 API Key"回调模式,升级后回调将被拒绝,请为链上
   监听器配置 `secret_key` 并改用 HMAC-SHA256 签名回调;
3. **安装向导**:全新部署的 `/install` 现在默认仅限本机访问,公网服务器安装请先在
   `.env` 配置 `ZCARD_INSTALL_ALLOWED_IPS=你的IP`,或使用 SSH 隧道;
   Docker/内网数据库部署请配 `ZCARD_INSTALL_ALLOW_PRIVATE_DB=true`;
4. **卡密加密**:升级后新导入卡密默认加密存储(需 .env 已有 CARD_ENCRYPTION_KEY,
   安装器均已生成);存量明文卡自动识别、正常发货,无需迁移;后台可显式关闭;
5. **在线更新/回退**:需输入管理员密码确认;回退不可低于 v1.12.85 且累计限 3 次;
6. 存量供货账号自动视为已审核,现有下游对接不受影响;
7. 若你的客服代码仍不显示:后台 → 店铺设置 → 客服设置,把代码引用的全部域名加入
   「受信域名白名单」后保存,保存时会即时提示是否生效。
