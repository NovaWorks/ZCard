# v1.12.37

## ✨ 支付宝当面付配置优化(SN 直填,免证书文件) + 支付渠道官方品牌图标

### 1. 支付宝当面付:新增 SN 直填模式

用户反馈当面付配置「配 2 个就能发起支付但一直失败」。原因是 yansongda v3
支付宝强制**证书模式**,必须提供「应用公钥证书 + 支付宝根证书」(路径或 PEM 内容),
仅配 app_id + 私钥会报「缺少 app_public_cert_path」。

**本次新增更简单的 SN 模式**(证书文件都免了):
- 配置新增 `应用公钥证书 SN` / `支付宝根证书 SN` 两个可选字段。
- **获取方式**:支付宝开放平台 → 密钥管理 → 查看应用公钥证书 / 支付宝根证书,
  **复制 SN 字段粘贴即可**(yansongda 优先读 SN,无需证书文件)。
- 证书路径/PEM 内容模式保留(与 SN 二选一)。

**当面付完整配置清单**(后台 → 支付设置 → 支付宝通道):
| 字段 | 必填 | 来源 |
|---|---|---|
| 应用 APPID | ✅ | 开放平台应用详情 |
| 应用私钥 | ✅ | 密钥管理(应用私钥/密钥) |
| 应用公钥证书 SN | ✅(推荐) | 密钥管理 → 查看应用公钥证书 → SN |
| 支付宝根证书 SN | ✅(推荐) | 密钥管理 → 查看支付宝根证书 → SN |
| 支付方式 | ✅ 选「当面付扫码」 | 生成二维码 |

> 前置条件:支付宝开放平台 → 产品中心 → **开通「当面付」**(及电脑网站/H5 对应产品),
> 未开通时下单会报「isv 产品未开通」类错误。

### 2. 支付渠道官方品牌图标(替换 emoji)

- 后端 9 个驱动 `getInfo()['icon']` 由 emoji 改为**品牌 key**(alipay/wechat/paypal/
  stripe/usdt/epay/codepay…),channels API 同步返回。
- 新增 `PayBrandIcon` 组件(storefront + sysadmin):**官方品牌色 SVG 徽标**
  (支付宝蓝 #1677FF / 微信绿 #07C160 / PayPal / Stripe / USDT 等),兼容 http 图片 URL。
- 应用位置:前台收银台/支付页支付方式图标、后台支付渠道管理列表与驱动选择器。
