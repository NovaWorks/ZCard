# v1.12.40

## 🐛 修复:后台开启登录验证码后 sysadmin 登录一直「验证码错误」

**现象**:后台开启「登录验证码」(captcha_login)后,管理后台(sysadmin)登录
必然失败,提示 `验证码错误`。

**根因**:storefront 与 sysadmin 共用 `POST /api/auth/login`。开启图形验证码后,
后端无条件校验 `captcha` 参数;而 sysadmin 登录页**只有滑块验证、没有图形验证码
输入框**,请求不带 captcha → 校验恒失败。

**修复**:
- sysadmin 全部请求带 `X-Client: sysadmin` 头(http 拦截器统一注入)。
- 后端 `AuthController::login`:**管理端来源跳过图形验证码**;
  前台(storefront)不受影响,仍按开关校验。
- 安全说明:管理端防暴力由路由 `throttle:5,1`(登录限流)承担,
  滑块为前端交互校验;前台图形验证码行为不变。
