# v1.12.63

## 📱 后台移动端适配优化(issue #8)

**需求**:站长反馈手机访问后台看着难受、部分功能操作不了。

**分析**:模板(art-design-pro)已有基础响应式(侧边栏移动折叠/内容区留白),
但**页面级元素**未适配:弹窗超屏、表格卡片过宽、工具栏/分页挤压、
搜索表单拥挤、统计卡片过大、设置页多标签无法横滑。

**优化**(新增全局样式 `sysadmin/src/assets/styles/core/mobile.scss`,
≤768px 生效,覆盖所有页面):

- **弹窗/消息框**:最大宽度 94vw,内容区可滚动 —— 手机端不再超屏,按钮可达;
- **抽屉**:全屏展示;
- **表格卡片**:内边距压缩、字号 12px、表体横向滚动 —— 多列表格可横滑查看;
- **工具栏/分页**:自动换行 + 紧凑间距;
- **统计卡片**:尺寸缩小,单列/双列更紧凑;
- **搜索栏**:表单项全宽排列,输入框/下拉/日期选择不再挤压;
- **设置页多标签**:横向滚动(可滑到「货源对接」等靠后的 tab);
- **详情描述**:单列展示;按钮组取消强制左距。
