# v1.12.56

## 支付回调地址修复

- 后台展示的异步通知地址改为根据当前访问域名动态生成，不再错误显示默认的 `localhost:8092`。
- 后台、Filament 管理页和支付驱动统一使用同一套 URL 生成逻辑。
- 展示地址与易支付实际提交的 `notify_url` 统一为 `/api/payments/notify/epay`。
- 保留原 `/api/payments/callback/epay` 路由，确保已经配置旧地址的平台仍可正常通知。
- 继续支持为独立回调入口配置 `notify_domain`，并保证展示地址与实际下单地址一致。

## 易支付兼容性修复

- 新增 RSA2 与 `SHA256WithRSA` 签名标识兼容，同时保留 MD5 和原 RSA 配置。
- RSA 私钥兼容 PKCS#1、PKCS#8、完整 PEM、裸 Base64 及转义换行格式。
- RSA 平台公钥兼容 PKCS#1、X.509、完整 PEM、裸 Base64 及转义换行格式。
- 兼容部分 GET 回调未正确编码 Base64 加号的情况。
- 支付成功状态同时支持 `TRADE_SUCCESS` 和 `TRADE_FINISHED`。
- 新增回调商户 PID 归属校验，避免错误商户通知被当前渠道接收。

## 回调处理与排查能力

- 支付流水改为按业务订单和支付渠道精确匹配，避免用户切换支付方式后核对到错误流水。
- 回调金额继续按支付流水中的实际收款金额严格核对。
- 增加脱敏的验签失败、订单匹配失败和金额不一致日志，不记录密钥及完整签名。
- 回调处理发生异常时返回标准失败响应，避免向支付平台暴露内部异常信息，并保留重试能力。
- 补充 MD5、RSA2、密钥格式、PID、成功状态、动态通知地址和完整订单入账回归测试。
