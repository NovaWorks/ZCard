## 🔧 本次更新内容

### 修复:货源同步/勾选导入 slug 唯一索引冲突(1062)

**现象**：商品删除后重新导入，或货源管理同步/导入时，报
`SQLSTATE[23000] Duplicate entry '1-xxx' for key 'products_merchant_id_slug_unique'`。

**根因**：商品使用软删除，删除后仍占用唯一索引；且上游商品 code/name 变化时
匹配不到原记录，导入走「新建」路径生成相同 slug → 唯一约束冲突。

**修复**（三层防御）：

1. **软删恢复**：导入时查找含软删除记录，删除过的商品重新导入**自动恢复**原记录（slug 不变）
2. **匹配放宽**：同货源下按「上游 code 或 slug」匹配——上游商品 code/name 变化时也能
   命中旧记录，**更新而非新建**
3. **插入兜底**：新建时捕获唯一约束异常 → 自动换随机后缀 slug 重试一次，任何边缘/并发
   场景都不中断导入
