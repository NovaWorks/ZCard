# v1.9.18

## 🔧 本次更新内容

### 卡密加密可开关(默认关闭)

店铺设置 → 安全设置 新增「**卡密加密**」开关，**默认关闭**：

- **关闭**（默认）：卡密**明文存储**，可直接导入卡密，**无需配置密钥**
- **开启**：需填写加密密钥，导入的卡密 **AES 加密存储**

### 随机生成密钥

开启加密后，密钥输入框右侧提供「**随机生成**」按钮，一键生成 32 字节 base64 密钥（与 `.env` 的 `CARD_ENCRYPTION_KEY` 同格式），复制保存即可。

### 历史数据风险提示

开启加密时若**已有历史卡密**，前端**弹窗 + 红字提示**：
- 历史明文卡密将无法解密展示，建议先导出备份再开启

### 兼容性保障

- **关闭时**：历史加密卡密仍可解密显示（检测到密钥自动解密；无密钥按明文返回）
- **开启时**：历史明文卡密降级按原文显示，不阻断展示/发货
