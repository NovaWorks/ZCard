# v1.12.85

## 🔒 安全修复：2026-08 安全审计整改（两轮审计全部落地）

> 本轮为两次系统安全审计的修复发布：① 全链路审计报告（本仓库 `SECURITY_AUDIT_REPORT.md`，
> 含 C-1/H-1~H-5 与 M/L 清单）；② 增量深挖审计（更新器 RCE 面 H1 除外——用户明确保留该端点设计）。
> 覆盖资金链路、管理后台、供货 API、安装流程与两个前端。

### 🔴 Critical

- **C-1 默认管理员凭据**：迁移/Seeder 中的占位管理员改为**随机密码 + status=0（禁用）**，任何路径都无法以默认凭据登录；Web 安装向导与 CLI `zcard:install` 是唯一激活并设置密码的入口（CLI 发现占位账号或仍在使用 `admin123456` 的历史账号时强制重置密码并打印一次）；新增应急命令 `php artisan zcard:reset-admin-password`（存量站点一键重置超管密码）。

### 高危

- **H-1 分站域名免验证**：`type=subdomain` 不再直写 verified/active，与 custom 一样必须完成 DNS TXT / HTTP well-known 归属验证；配置了 `subsite_subdomain_base` 时强制校验子域后缀；禁止绑定主站自身域名。
- **H-2 安装向导重跑接管**：安装接口的"已安装"判定升级为锁文件 + 数据库双保险——`users` 表存在启用管理员即拒绝重跑安装（锁文件丢失也无法覆盖 admin 密码接管站点）；`test-db` 拒绝内网/链路本地数据库地址（本机回环除外），防安装向导被用作内网盲探测。
- **H-3 供货回调 SSRF**：回调发送 `withoutRedirecting()` + `CURLOPT_RESOLVE` 钉死已校验公网 IP + 校验全部 A/AAAA 记录 + IPv6 私网/回环/链路本地/组播/CGNAT 段全封禁 + 强制 HTTPS（与 M5 同源修复）。
- **H-4 零价供货套卡**：供货价必须 > 0——未配置专属价且 `factory_price=0` 时下单直接拒绝（`price_not_configured`）；后台专属价接口 `price` 校验改为 `min:1`。
- **H-5 优惠券并发双花**：`CouponService::apply` 改为条件原子更新（仅 `status=active` 可核销），0 行即抛异常回滚订单。
- **H2（审计②）管理员资金越权**：`bills/adjust` 禁止对本人账户调账；`users/{id}` 移除 `balance` 直写——余额只能经 `BillService` 变动并产生流水。
- **H3（审计②）CSV 公式注入**：新增 `App\Support\CsvSafe`，订单/卡密/优惠券导出对 `= + - @ \t \r` 开头单元格加 `'` 前缀。
- **H4（审计②）微信支付回调修复**：回调携带原始 body 与全部 `Wechatpay-*` 头交 SDK 验签（此前 headers 被丢弃恒 fail）；`Pay::config` 增加 `_force` 重建容器（修复 Laravel PayServiceProvider 预初始化吞掉通道配置的问题，微信下单签名同样受益）；修正 V3 解密资源解析路径；支持配置平台证书序列号；新增验签/篡改/金额不符 3 个回归测试。

### 中危（合并两轮清单）

- **下单/支付限流**：`/orders`、`/orders/batch`、`/payments/create`、`/payments/batch-create` 增加 `throttle:20,1`；安装接口限流；`/api/supply/callback` 增加 `throttle:60,1`。
- **客服脚本域白名单**：脚本引用的外部域名必须在 `service_widget_allowed_hosts`（可后台配置，默认 Chatwoot/Crisp 官方域名）内，内联代码引用非 HTTPS/未授权主机整段丢弃；商城 CSP `connect-src` 收紧为本站 + 白名单来源；设置页增加危险提示。
- **认证令牌安全**：前后台 token 不再落 localStorage（仅内存），登录态由 **HttpOnly Cookie 会话**承载（Sanctum SPA）；登出/改密同时失效会话；锁屏移除客户端 AES 伪加密与 disableDevTools；纯 Bearer 的 API 客户端不受影响。
- **登录/注册/找回密码防护**：登录与注册验证码默认开启（新装）；注册验证码校验先于唯一性（防无验证码枚举）；登录增加账号级失败锁定（5 次锁 15 分钟）；找回密码发送失败返回与成功一致响应（收敛邮箱枚举）。
- **查单防爆破**：`/orders/query` 按 IP+关键字计数，5 次"命中但未授权"锁 15 分钟；下单查询密码最小长度 6 位。
- **关单竞态**：`closeExpired`/`closeOrder` 事务内行锁复检 `pending`，已支付订单绝不会被翻成 closed。
- **上游回调防重放**：dujiao-next 补时间戳窗口；ZCard 驱动补 per-source nonce 一次性校验；验签通过后才写 nonce。
- **供货 nonce 命名空间**：nonce 键绑定 api_key（防账号间投毒）；database 模式以 `namespace|nonce` 落库。
- **M-4 供货源凭证脱敏**：改为白名单式——除 `app_id/merchant_id/pid` 外一律掩码；模型级 `$hidden` 双保险（响应显式回填掩码值）。
- **M-5 设置数值边界**：`StorefrontConfig::setMany` 按 key 校验（提现手续费≥0、佣金率 0-100、限流≥1、关单分钟 1-1440、充值上限>0 等），越界 422。
- **M-8（审计②）密钥脱敏补漏**：`admin_alert_tg_token` / `admin_alert_wecom_webhook` 加入 `SECRET_KEYS`。
- **M-9（审计②）分站提现状态机**：`approve/reject` 增加 `pending` 校验。
- **M-10（审计②）供货余额负值防护**：`adjust` 负数不得使余额小于 0。
- **M-11（审计②）mock-pay 门禁**：要求显式 `ZCARD_ALLOW_MOCK_PAYMENT=true` 且禁止 production。
- **M-14 UsdtDriver**：支持回调 HMAC-SHA256 签名（`secret_key` 配置，比静态 API Key 更安全；未配置时回退兼容）；USDT/OKPay/TokenPay 回调金额 ±1 分容差（修复往返截断导致的"付款成功不发货"）。
- **M-15 模型序列化收窄**：`SupplySource.credentials`、`OrderDelivery.card_content`、`Payment.raw`、`SubsiteDomain.verification_token` 全部 `$hidden`。
- **M-16 异常文案收敛**：批量下单/创建支付失败不再向客户端回显内部异常细节（日志记录 + 统一文案）。
- **L-1 卡密导入 dedup**：仅请求显式携带时才覆盖商品级去重设置。
- **L-5 供货 API 分页上限**：`page_size` 上限 100；库存接口拒绝非上架商品。
- **L-10 分站公告清洗**：分站 announcement 覆盖路径同样过 `HtmlContentSanitizer`。
- 其余：卡密解密失败 debug 日志；素材原始文件名入库前剥离标签；已售卡密禁止状态回退；供货 API nonce/时间戳格式约束；后台订单导出统一走 http 封装；登录 redirect 校验；`v-highlight` DOMPurify 清洗；后台 iframe 仅 HTTPS + sandbox。

## 升级与使用

- 通过后台「在线更新」或 `git pull && composer install --no-dev && php artisan migrate` 升级。
- **存量站点安全检查**：如曾用 CLI 安装且从未改过 admin 密码，立即执行 `php artisan zcard:reset-admin-password`。
- 微信支付通道：建议补填「微信支付平台证书序列号」（可选）。
- USDT 通道：建议配置回调 HMAC 密钥（`secret_key`），链上监听器按字段名排序拼接后 HMAC-SHA256 签名。
- 客服脚本使用自建 Chatwoot/Crisp 域名的站点，请在「设置 → 在线客服」的受信域名白名单中追加对应域名。
- 供货 API 下游注意：①未配置供货价的商品将拒绝下单；②回调 URL 现在必须为 HTTPS 且解析到公网 IP。
- 未安装站点建议在 `.env` 配置 `ZCARD_INSTALL_ALLOWED_IPS` 限定安装来源 IP。
