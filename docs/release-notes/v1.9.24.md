# v1.9.24

## ✨ 本次更新内容

### 1. 修复:分类抽屉样式显示不全

前台 `category_nav_style = combo`（抽屉样式，顶部分类 + 下拉子分类）时，子分类下拉菜单
因绝对定位在 `overflow-x-auto` 横向滚动容器内部而被裁剪，导致分类显示不全；且 `group-hover`
在移动端触摸屏完全失效。

**修复**：子分类改为独立面板（挂在无 overflow 的外层容器上，完整展示不被裁剪），
桌面悬停自动展开、点击切换，移动端点击一级分类即可展开子分类。

### 2. 修复:后台关闭库存后详情页仍显示库存

商品列表卡片已遵循 `show_stock`/`show_sales` 开关，但**商品详情页**的评分汇总区
（销量/库存数字）无条件渲染。已补齐：销量、库存、评价数均受后台对应开关控制，
关闭后前台详情页不再显示。

### 3. 新增:商品虚拟评价表单化管理

后台「商品管理 → 编辑 → 虚拟数据」Tab 中，虚拟评价由**手填 JSON** 改为**表单式管理**：
逐条填写评论人昵称 + 星级 + 内容，支持添加/删除，保存时自动序列化为 `{rating, count, list}`
结构，与现有真实+虚拟评价合并逻辑无缝衔接。虚拟销量输入框保留（基础信息 Tab）。

### 4. 新增:商品详情图点击放大

前台商品详情页点击主图可全屏放大预览（lightbox）：支持点击遮罩/右上角 ✕ 关闭、
左右箭头切换多图、键盘 ←/→/ESC 操作，打开时锁定页面滚动。

### 5. 优化:语言/货币切换器移至右侧尾部 + 修复时隐时现

- 桌面端货币/语言切换器从导航中间移至**右侧尾部**（用户区/登录注册之后，独立分隔线分组）
- **修复"有时显示有时不显示"**：切换器显隐条件增加 `prefs.loaded` 守卫——此前 `currencies`
  初始为空数组、`languages` 初始为 `['zh','en']`，在配置异步加载完成前会渲染一次错误的
  显隐状态（首帧闪烁/加载后消失），现改为配置加载完成后按真实语言/货币数量渲染，稳定一致

### 6. 基建:storefront 类型检查恢复可用

- `typescript ^7.0.2`（预览版）与 `vue-tsc 3.3.8` 不兼容导致 `pnpm typecheck` 长期不可用，
  降级 TS 至 `~5.9.0` 并开启 `skipLibCheck`（规避 vue-i18n lib 类型缺陷）
- 顺带修复该过程中暴露的历史类型问题：`Category` 类型补 `icon` 字段、
  `supplier.ts` API 缺失响应类型泛型（axios `R`）、`preferences.ts` locale 类型断言、
  `Product.vue` `priceDisplay` 死代码分支与缺失的 `onBeforeUnmount` 导入
