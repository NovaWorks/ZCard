# v1.12.23

## ✨ 新增:公告入口移到推广中心后 + 帮助中心双语演示(后台可配)

### 1. 首页公告入口位置调整

客户反馈公告位置不对。原公告入口在**顶部品牌条**(深蓝渐变条左侧 slogan 之后),
本次移到**主导航「推广中心」之后**(登录区):

```
首页 | 订单查询 | 🛒 | 我的订单 | 推广中心 | 📢公告 | 分站 | 用户
```

- 桌面导航与移动端菜单同步调整。
- 顶部品牌条恢复为纯 slogan + 安全支付提示。
- 游客首次访问仍自动弹出公告弹窗(机制不变);公告入口仅登录用户导航可见
  (与推广中心同级,推广中心本身仅登录可见)。

### 2. 帮助中心后台演示 + 多语言标题

后台「设置 → 页脚配置 → 帮助中心」JSON 编辑器新增:

- **「填入示例」按钮**:一键填入含中英双语标题的演示数据。
- **格式说明更新**:标注 `title_en` 字段用法。

**多语言机制**:帮助中心链接标题支持双语 —
`[{"title":"常见问题","title_en":"FAQ","url":"/orders/query"}]`

- `title` = 默认语言标题;`title_en` = 英文标题。
- 前台英文界面显示 `title_en`,**缺省自动回退 `title`**(旧数据无 `title_en` 不受影响)。
- 默认值已带双语演示(FAQ / Purchase Guide),开箱即用。
