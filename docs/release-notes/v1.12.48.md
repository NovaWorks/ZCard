# v1.12.48

## 🐛 修复:货源拉取报 Data too long for column 'name'(商品名超长)

**现象**:上游商品名很长(如「💎【带余额带消费记录】美国-香港-…」几百字符),
同步时报 `SQLSTATE[22001]: Data too long for column 'name'`。

**根因**:`products.name` 为 varchar(150)、`slug` varchar(150),上游商品名远超
该长度(尤其含国家列表的商品)。

**修复**(双保险):
1. **迁移扩容**:`products.name` 150→**500**、`slug` 150→**250**
   (`2026_08_11_072252_enlarge_product_name_and_slug_length`)。
2. **代码截断**:`SupplySyncService` 同步/更新商品时,`name` 截断到 500、
   `slug` 截断到 250(超长不再报错,尾部保留前 500 字符)。

## 验证

- `SupplySyncServiceTest` 新增用例:超长商品名(数百字符)同步成功,
  name ≤ 500 / slug ≤ 250。
- 全量 212 通过 / 664 断言。
- ⚠️ 需执行迁移:`php artisan migrate`(在线更新自动执行)。
