# v1.11.4

## 🐛 修复:服务器 composer install 报错 `/tmp/.composer/config.json is not readable`

**现象**:生产服务器执行 `composer install` 报 `The file "/tmp/.composer/config.json" is not readable`,
安装中断。

**原因**:Composer 默认把全局配置写到 `$COMPOSER_HOME`(未设置时通常是 `/tmp/.composer` 或 `~/.composer`)。
服务器上该文件可能由其他用户(root/部署脚本)创建,导致运行用户(如 `www-data`)无读权限。

**修复**:在 `composer.json` 中显式配置 `config.home` 与 `config.cache-dir` 指向**项目根目录下的 `.composer/`**:

```json
"config": {
    "home": "./.composer",
    "cache-dir": "./.composer/cache",
    ...
}
```

Composer 从项目内读取/写入其全局配置与缓存,完全绕开系统 `/tmp` 或用户 `HOME` 的权限冲突,
不再依赖服务器环境。`.composer/` 已加入 `.gitignore`,不会进入版本库。

**验证**:
- `composer install` 正常执行,`.composer/` 自动生成在项目根目录
- 与 PHP 8.3 平台约束(见 v1.11.3)配合,服务器上直接 `composer install` 即可

## ⬆️ 升级

在线更新:后台 → 在线更新 → 一键更新。更新后重新执行:

```bash
composer install
```

即可正常完成(首次会生成项目内 `.composer/` 目录)。
