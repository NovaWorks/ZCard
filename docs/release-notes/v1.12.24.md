# v1.12.24

## ✨ 新增:双端图标系统升级——emoji 全面替换为 Remix Icon

客户反馈所有图标难看(emoji 跨平台渲染差异大、无法染色、风格玩具感)。
本次将 storefront 与 sysadmin 的图标统一升级为 **Remix Icon**(ri: 前缀,Iconify 生态):

### 1. storefront(顾客前台)

- 引入 `unplugin-icons` + `@iconify-json/ri`:**编译期内联 SVG**,产物零运行时请求、
  无字体文件、无 FOUC,契合"产物提交仓库、生产免 Node"部署模式。
- 新增统一图标组件 `AppIcon.vue`(name → 图标映射,与 sysadmin 命名一致)。
- 替换 18 个文件约 80 处 emoji:导航(购物车/公告/用户)、页脚信任徽章
  (极速→rocket / 安全→shield-check / 在线→time / 客服→customer-service)、
  支付方式(支付宝/微信/QQ/网银/PayPal/Stripe/USDT 品牌图标)、分类导航、
  空状态、加载/成功/失败/超时状态、用户中心、充值、安装向导等。
- 图标全部按表达意图选择(如"极速发货"用 rocket、"订单"用 archive、"清理"用 eraser)。

### 2. sysadmin(管理后台)

- 沿用现有 `@iconify/vue` + `ArtSvgIcon` 组件,**零新依赖**。
- 替换 17 个文件约 90 处 emoji:统计卡片、仪表盘 KPI/告警、按钮图标、
  输入框 prefix、媒体管理器、在线更新页、提现/优惠券/订单等列表页。
- **分类图标选择器(icon-picker)改为 Remix 图标库**(5 组 80 个图标)。

### 3. 数据兼容

- 分类图标、社交图标等**用户配置数据**支持 `ri:` 前缀:
  storefront 渲染顺序为 图片 URL → ri: 图标 → emoji 字符,**旧 emoji 数据不受影响**。

## 验证

- storefront typecheck/build 通过,产物已更新(public/storefront)。
- sysadmin build 通过(含 vue-tsc),产物已更新(public/admin)。
- 残留 emoji 扫描干净(仅保留 ✓/✘/★ 状态文本符号)。
- 视觉抽查:首页/订单查询页 SVG 渲染正常、无控制台错误;sysadmin 登录页
  ArtSvgIcon(iconify--ri)渲染正常。
