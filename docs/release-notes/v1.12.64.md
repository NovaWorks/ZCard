# v1.12.64

## 🐛 修复:PHP 8.3 下货源同步报 readonly 属性错误(库存补查)

**现象**:PHP 8.3 环境点「同步商品」报错(货源同步失败),8.4+ 环境正常。

**根因**:`AcgFakaDriver::fillMissingStocks` 补查库存时对 readonly 的
`UpstreamProduct` 用 `clone $dto` 后重新赋值 —— **PHP 8.3 不允许
clone 后修改 readonly 属性(PHP 8.4 才引入该放宽)**,8.3 直接抛
"Cannot modify readonly property"。

**修复**:改为**重新构造 DTO**(named arguments 传入修正后的 stockQuantity)
并替换原数组项 —— **PHP 8.3 / 8.4 / 8.5 全兼容**,不再依赖 clone 赋值。

**验证**:
- 新增 `AcgFakaStockFetchTest`:Http::fake 模拟上游 items(自动发货带 stock /
  手动发货不带)+ stock 接口,断言补查后手动发货商品库存 = 真实值(8),
  自动发货商品保持 items 自带值(5)。
- 全量 263 通过 / 856 断言。
- 后端无迁移。
