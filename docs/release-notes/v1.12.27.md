# v1.12.27

## ✨ 新增:余额支付下单(充值余额直接付款,订单管理可见)

客户要求:用充值余额下单后,订单管理也要能看到这笔订单。
此前系统无余额支付功能,本次实现完整闭环:

### 1. 余额支付(storefront)

- **收银台/支付页新增「余额支付」选项**(登录用户可见,展示当前余额,
  充值页不提供余额支付防止循环充值)。
- 后端 `POST /api/payments/balance`(单订单)/ `POST /api/payments/balance-batch`(购物车聚合):
  校验订单归属与状态 → `BillService` 余额扣款(行锁+余额不足校验+流水) →
  逐单 `markPaid`(触发 OrderPaid 事件:自动发货/分销佣金/会员升级)。
- 订单写入 `payment_channel=balance`。

### 2. 订单管理可见

- 余额支付订单与普通订单同表,**后台订单管理天然可见**;
  支付渠道列映射显示「余额支付」。
- 余额不足/非本人订单/重复支付均被拒绝(测试覆盖)。

### 3. 修复:路由文件中间 use 不生效(EnsureInstalled 测试回归)

调试余额支付测试时发现 `routes/api.php` 中**位于可执行语句之后的 use 语句
在 Laravel 13 路由加载时部分不生效**(如 `InstallController::class` 解析为裸类名
→ 未安装场景 500)。已将所有 use 移到文件顶部(49 条),`EnsureInstalledMiddlewareTest`
恢复 9/9 绿。
