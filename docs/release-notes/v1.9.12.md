# v1.9.12

## 🔧 本次更新内容

### 拉取上游商品弹窗:实时定价策略

「货源管理 → 拉取上游商品（勾选导入）」弹窗新增**定价策略**，勾选导入前即可定价：

- **定价模式**：按比例加价 / 按固定金额加价 / 平价（=成本）/ 留空待定（不自动上架）
- **实时预览**：商品列表实时显示「上游价 → 售价」，切换模式或修改参数立即刷新
- **保存为货源默认**：勾选后导入同时把该策略保存为货源默认定价（下次打开弹窗自动预填）
- **重新定价**：已导入的商品本次导入按所选策略重新定价
- **待审模式**：售价显示「待审」，导入后商品不自动上架（`status=0`），需手动上架

定价基准沿用现有逻辑：优先上游成本价（`factory_price`），上游未设成本时回退上游售价（`price`）；未选择策略时按货源默认定价规则。
