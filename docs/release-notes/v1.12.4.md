# v1.12.4

## 🐛 修复:商品编辑页「购买方式」显示原始键名

**问题**:sysadmin 商品编辑 → 价格与库存 → 购买方式(RadioGroup)使用了未定义的
i18n 键 `zcard.product.pickType` / `pickGeneral` / `pickPremium` / `pickPremiumHint`,
页面直接显示原始键名而非中文/英文。

**修复**:补齐 zh/en 语言文件:

| 键 | 中文 | English |
|---|---|---|
| `pickType` | 购买方式 | Purchase Mode |
| `pickGeneral` | 常规购买 | Regular Purchase |
| `pickPremium` | 靓号自选 | Premium Number |
| `pickPremiumHint` | 开启后买家需先选择靓号再下单,每个靓号独立定价 | Customers must pick a premium number before checkout; each number is priced individually |

与 v1.12.1 修复的卡密导入页 `cardTypePremium` 同款问题,一并收尾。
