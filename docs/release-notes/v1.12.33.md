# v1.12.33

## ✨ 新增:我的订单「待支付」订单增加「去支付」按钮

**现象**:「我的订单」里待支付(pending)订单只有提示文字,没有支付按钮,
用户无法从订单列表继续完成支付。

**本次实现**(`storefront/src/views/MyOrders.vue`):
- pending 订单卡片右侧新增「**去支付**」按钮。
- 点击跳转现有支付页 `/pay/{orderNo}`——该页列出全部支付通道
  (第三方通道 + **余额支付**),用户任选完成支付。
- 按钮文案中英双语(`order.myOrders.payNow`)。

**说明**:
- 若订单已超时被系统关闭(如 15 分钟未支付),支付页会提示「订单状态异常」,
  属预期行为(可重新下单)。
- 余额支付需登录且余额充足,与收银台行为一致。
