# v1.12.76

## 🔄 定时价格核对任务 + 🐛 历史商品加价不生效修复

### 1. 同步任务统计:价格更新/下架数

任务弹窗与记录新增统计维度(全量核对时更直观):
- **价格更新数**(`price_updated_count`):本次同步中售价实际发生变化的商品数
  —— 上游调价 → 自动重算 → 每轮同步都能看到"成功更新价格多少个产品";
- **下架数**(`hidden_count`):上游下架商品(status=0)同步后本地标隐藏;
  **全量核对**时,上游已删除/彻底消失的商品也会被检测并标隐藏 + 计数。

### 2. 全量价格核对任务(长期驻扎)

- 定时调度新增:**每天一次全量核对**(对开启自动同步的货源),
  拉全量比对价格与在售状态,保证上游改价/下架**每天自动落库**;
- 每小时增量同步(原有)+ 每天全量核对(新增),两次定时核对互为补充;
- 所有核对任务都建任务记录,在货源「查看任务」弹窗可见(状态/进度/统计),
  手动同步、定时增量、定时全量三种任务同列表可查。

### 3. 🐛 修复:历史商品加价不生效(客户反馈)

**根因**:前端编辑商品时**总是提交 price 字段**,后台原先"请求含 price 就置
price_manual=true"——导致运营只要编辑过商品(哪怕只改名称/描述),该商品
就被误标为"手动改价" → 货源同步时不再重算售价 → **上游调价后历史商品不跟随**。

**修复**:
- 仅当**价格实际发生变化**时才标记保护(改价→保护,编辑其他字段→不误标);
- 商品编辑抽屉对上游商品新增「**跟随上游调价**」开关:
  开启(默认)= 恢复自动定价,同步按加价规则重算;关闭 = 保护手动价;
- 已误标的商品:编辑保存一次(打开「跟随上游调价」)即可解除。

**历史商品加价生效路径**:更新本版本 → 打开商品编辑确认「跟随上游调价」开启 →
货源点一次「同步商品」(或等每小时增量/每天全量核对)→ 售价按**上游售价+加价规则**
自动重算(v1.12.71 已修正基数为上游售价)。
