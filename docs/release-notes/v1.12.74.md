# v1.12.74

## 📦 订单详情增强:上游链接/成本利润 + 手动发货兜底 + 重新拿货

### 1. 订单详情:上游货源信息 + 财务明细

详情弹窗新增「上游货源信息」区块:
- **货源名称**、**上游单号**(拿货记录);
- **上游商品链接**:点击直达上游商品页(acg-faka 默认拼 /buy/{code};
  可在货源设置配置 `product_url_template` 模板自定义,支持 {base}/{code} 占位;
  链接打不开时回退显示货源站点地址)。

财务字段补齐:单价、成本单价、**利润(金额+利润率百分比)**,负利润红色高亮。

### 2. 上游订单支持手动发货(兜底)

- 之前仅 `manual` 类型订单可手动发货,**上游商品订单拿货失败/上游人工发货时
  本地无任何兜底手段** → 现在 `upstream` 订单同样开放「手动发货」,
  填写内容即可完成交付;
- 与上游回调幂等兼容(已发货订单不会重复发货)。

### 3. 手动重新拿货(自动拿货失败的兜底)

- 订单列表 upstream 商品新增「**重新拿货**」按钮:
  立即向上游重新提交拿货请求(同步等待结果);
- 成功 → 自动发货;上游已接单未发卡 → 提示上游单号,等待回调/重试;
- 失败 → 展示**具体错误原因**(如商品已下架/价格变动),并提示可改用手动发货;
- 已发货/非上游商品/未支付订单均校验拦截。

### 关于「没有自动拿货」的说明

自动拿货链路 = 支付事件 → 同步拿货(失败自动转异步 Job 重试 5 次)。
**异步重试依赖队列 worker 运行**(v1.12.73 起货源「查看任务」可检测队列状态);
若队列未开启且同步拿货失败,订单会停在待发货 —— 现在有了两道兜底:
**重新拿货**(再触发)与**手动发货**(人工介入),不再需要关闭自动发货。
