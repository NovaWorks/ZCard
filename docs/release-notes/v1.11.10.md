# v1.11.10

## ✨ 优化:商品封面图/详情图接入素材管理器 + 素材管理删除入口明确

### 1. 商品封面图 / 详情图接入素材管理器

新增商品、编辑商品的**封面图**与**详情图**现可调用素材管理器:

- **封面图**:上传区下方新增「选择图片」按钮,打开素材库弹窗单选,选中后回填为封面
- **详情图**:上传区下方新增「从素材库选择」按钮,打开素材库弹窗**多选**,选中图片追加到商品图集

两个字段均保留原有本地上传(快捷上传到服务器),同时支持从素材库选择,统一图片资源管理。

### 2. 素材管理删除入口明确

**现象**:素材管理页面找不到删除图片的入口,操作按钮依赖鼠标 hover 且为 emoji 图标,不易发现。

**修复**:
- 每张图片卡片底部新增**常驻操作栏**:「🔗 复制 / ⬇ 下载 / 📁 移动 / **删除**」——"删除"为明确文字按钮,始终可见,触屏/鼠标均可直接使用
- 卡片左上角 hover 操作条精简为「预览 / 复制」(保留大图预览入口)

**验证**:
- 商品表单:封面「选择图片」→ 素材弹窗 → 选中 → 确定 → 封面回填
- 素材管理:卡片底部「删除」按钮常驻 → 点击 → 确认弹窗 → 删除成功
- 162/162 测试通过
