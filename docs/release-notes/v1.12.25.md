# v1.12.25

## 🐛 修复:站点 Logo 上传按钮显示 ArtSvgIcon 标签文本 + 帮助中心双语预览

### 1. 修复:站点 Logo 上传按钮显示 `<ArtSvgIcon icon="ri:camera-line" />`

**现象**:后台站点 Logo / 图片上传按钮显示出原始的组件标签文本。

**根因**:v1.12.24 图标升级时,`image-picker` 组件中 `{{ uploading ? '...' : '📷' }}`
是 JS 三目表达式(文本插值),批量替换把 `<ArtSvgIcon>` 组件标签塞进了字符串,
文本插值不解析 HTML → 字面渲染出标签文本。全库排查确认仅此一处。

**修复**:改为模板内真实组件渲染(`v-if="!uploading"`,loading 时 ElButton 自带 spinner)。

### 2. 新增:帮助中心双语预览(后台)

后台「设置 → 页脚配置 → 帮助中心」JSON 编辑器下方新增**前台效果预览**:
实时解析当前 JSON,并排展示中英文标题效果(中文 title / English title_en,
无 title_en 自动回退中文),保存前即可确认多语言配置。
