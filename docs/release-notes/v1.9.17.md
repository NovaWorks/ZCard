# v1.9.17

## 🔧 本次更新内容

### 卡密加密密钥支持后台配置

**问题**：导入卡密报 `CARD_ENCRYPTION_KEY 未配置`——卡密加密密钥只在 `.env` 配置，线上未配置就无法导入卡密。

**修复**：店铺设置 → 安全设置 新增「**卡密加密密钥**」配置项：

- 后台填写保存即可生效，**无需修改 .env**
- 密钥解析优先级：**后台配置 > `.env` 的 `CARD_ENCRYPTION_KEY`**
- **留空 = 保持原值**（不会误清）
- ⚠️ 界面红字提示：**修改后已加密的历史卡密将无法解密**，建议安装时设置后不再变更

**安全设计**：
- 密钥 `Crypt` 加密存储于 `settings` 表（非明文）
- 所有接口 / 页面回显 `••••••••` 脱敏（含前台 settings API）
- 真实值仅 `CardCipher` 内部直接查表解密使用，不经过任何响应
