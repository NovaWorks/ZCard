# v1.12.86

## 🔑 CLI 安装管理员密码策略（C-1 补强）

**客户反馈**：CLI 安装（`php artisan zcard:install`）不传 `--password` 时，管理员密码应使用更强的随机值并明确显示在命令行中。

## 修复内容

- `zcard:install` 两条路径（新建 admin / 重置占位 admin）统一使用 **16 位字母+数字随机密码**（无特殊符号，便于终端显示与复制；此前新建路径为 8 位）；
- 安装完成区显式打印管理员凭据：`用户名 / 邮箱 / 密码`，并提示"仅显示一次、请立即修改"；
- `--password` 显式传参的行为保持不变（使用传入值并同样打印）；
- 新增回归测试：不带 `--password` 的 CLI 安装 → 生成随机密码、命令行可见、不等于任何默认密码、账号激活并具备 super_admin 角色（`CriticalSecurityFixTest`）。

## 升级与使用

- 通过后台「在线更新」或 `git pull && composer install --no-dev` 升级；无数据库变更。
- 提示：存量站点如需重置超管密码，仍可使用 `php artisan zcard:reset-admin-password`。
