# v1.9.7

## 🔧 本次更新内容

### 1. 列表页分页栏被卡片裁切（看不到分页 / 无法往下拉）

**问题**：列表页容器 `.art-table-card`（`overflow: hidden`）+ `art-full-height` 固定高度，
数据满页时表格内容被撑高到 1100px+，分页栏渲染到卡片可视区之外被**裁掉**，
且页面高度被锁定、无内容可滚 → 表现为「看不到分页 / 无法下拉」。

**修复**：新增 `useListTableHeight` hook，测量卡片 / 表格 / 分页栏高度，给原生 `ElTable`
设置自适应 `height`（表格内部滚动，分页栏保持在卡片可视区内），
应用到全部 **11 个原生 ElTable 列表页**：

`商品`、`订单`、`卡密`、`用户`、`账单`、`提现`、`优惠券`、`分销`、`评价`、`货源`、`供货账号`

### 2. 列表页 keep-alive 缓存导致数据 / 分页不刷新

**问题**：10 个列表页路由配置了 `keepAlive: true`，但数据加载只挂在 `onMounted`。
页面被 `<KeepAlive>` 缓存后，**切换标签页回来不会重新挂载 → 不重新请求 → 数据、total、
分页停留在旧状态**（新增商品/订单后切回列表页看不到新数据，看起来「没有分页」）。

**修复**：数据加载钩子从 `onMounted` 改为 `onActivated`（keep-alive 缓存组件每次激活时触发，
首次挂载也触发），切回列表页即重新拉取最新数据。
