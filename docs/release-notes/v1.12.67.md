# v1.12.67

## 🐛 修复:前台刷新闪出默认"ZCard"品牌(logo/站名不统一)

**反馈**:后台已配置 logo 和网站信息,但前台每次刷新都会短暂/持续出现默认 ZCard 字样,各页面表现不一致。

**根因**(前端时序竞态):
1. `index.html` 硬编码标题「ZCard 商城」;
2. 前台配置(`getStorefrontSettings`)是**异步**加载,刷新瞬间配置尚未到达;
3. 期间顶栏渲染**硬编码 "Z" 字母方块** + 站名回退默认 "ZCard";浏览器标签页标题也回退 "ZCard";
4. 商品详情页 SEO 只在加载完成时设置一次,若配置晚于商品到达,标题会覆盖成默认值。

### 修复

1. **配置本地缓存(`localStorage`)**:
   - 刷新时**同步恢复上次配置**,logo/站名/标题首帧即为后台配置,不再闪默认品牌;
   - 网络请求照常拉取最新配置并覆盖缓存(后台改配置后刷新即时生效)。
2. **移除硬编码品牌**:
   - 顶栏无 logo 占位方块由 "Z" 改为**站名首字**(未配置时不显示字母);
   - 顶栏/页脚站名回退值不再硬编码 "ZCard";
   - `index.html` 默认标题改为中性的「在线商城」。
3. **商品详情页 SEO 响应式化**:
   - 标题随配置到达自动重设为「商品名 - 后台站名」,修复竞态覆盖;
   - `og:site_name` 修正为站点名称(此前误用完整标题)。

## 验证

- storefront build + vue-tsc 类型检查通过,产物已重建。
- 后端无改动。
