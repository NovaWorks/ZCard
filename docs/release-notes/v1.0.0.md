ZCard 是一套现代化的虚拟商品自动发卡 / 个人店铺系统，采用 Laravel 13 + Vue 3 双栈构建。

## 🛒 核心功能
- **商品/卡密/SKU**: 分类(树形)、多 SKU、会员等级定价、最低/最高起购、限购、精选/热标签、虚拟评价、自定义购买控件
- **卡密系统**: AES 加密存储 + sha256 去重(可开关)、批量导入(≤5000同步/>5000队列)、预选加价、导入批次撤销
- **库存防超卖**: 行锁(lockForUpdate) + 事务原子性
- **订单**: 游客下单 + 查询密码、订单号/联系方式搜索、自动关闭超时订单

## 💳 支付
- **9 大支付通道**: 支付宝、微信支付、PayPal、Stripe、易支付、码支付、USDT(TRC20)、EpuSdt
- 每通道独立配置凭据/手续费/排序/启停
- 回调统一做凭据校验(防空 key 伪造) + 金额核对 + 幂等

## 💰 多货币
- 基础货币(CNY)为唯一记账真理源，所有金额以「分」整数存储
- 客户可切换显示货币(前台切换器)，按汇率实时换算
- 下单瞬间锁定汇率快照，历史订单不随汇率变动

## 🌐 多语言
- 前台 vue-i18n 中/英双语，即时切换
- 后端 API `__()` 全量提取(Accept-Language / X-Lang 头控制)

## 👥 三级分销
- 推广链接注册绑定 pid 上下级链
- 按毛利 × 每级费率向上追溯最多 3 级发佣
- 自推荐拒绝、自购拦截(CommissionService 互斥)
- FIFO 提现 + 后台审批

## 🏪 分站(白标店铺)
- 分站 = 主站的加价分销渠道(转售主站商品)
- 域名验证(DNS TXT + HTTP)、加价策略(比例/固定/继承)
- 防自购、利润冻结期账本、FIFO 提现

## 🛠️ 后台(sysadmin)
- Vue 3 + Element Plus SPA
- 商品/订单/卡密/用户/评价/优惠券/货币/分站 全功能管理
- 在线更新(git pull + 自动构建)、版本回退
