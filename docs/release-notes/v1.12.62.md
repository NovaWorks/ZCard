# v1.12.62

## 🐛 修复:Cloudflare Rocket Loader 导致 admin SPA 空白(issue #11)

**现象**:站点在 Cloudflare 之后(开启 Rocket Loader),更新后打开 `/admin`
页面空白(`#app` 空注释),API/静态资源均 200,无任何报错。

**根因**:Cloudflare **Rocket Loader** 改写页面 `<script>` 标签(异步延迟加载),
对 ES Module 脚本处理不当 → Vue 应用未执行 → SPA 空白且静默。

**修复**:
1. **构建产物**(storefront + sysadmin 的 vite `transformIndexHtml`):
   给所有 `<script type="module">` 入口加 **`data-cfasync="false"`** ——
   Cloudflare 跳过 Rocket Loader 处理,module 正常执行。
2. **storefront 生产错误处理器**:`app.config.errorHandler` 生产也保留
   console.error(组件/路由/异步加载错误不再静默,便于诊断空白页)。
   (sysadmin 已有完整全局错误处理,无需改动)
3. **部署指南**新增「问题 15:更新后后台/前台空白页(Cloudflare Rocket Loader)」,
   含验证命令与手动关闭 Rocket Loader 备选方案。
