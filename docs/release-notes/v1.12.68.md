# v1.12.68

## 💬 客服浮窗改为原生脚本模式 + 🖼️ 站点 favicon 支持

### 1. 客服浮窗:第三方脚本原生实现(不再嵌套本站按钮)

**反馈**:嵌套的客服浮窗配置了却不显示,且第三方(Chatwoot/Crisp)自带气泡
与本站按钮叠加易出问题,希望直接原生跑第三方脚本。

**修复**:

- **注入时序 bug**:此前脚本只在组件挂载时注入一次,而前台配置是异步加载的,
  配置到达时组件已挂载 → **脚本永远不会执行**。现改为**响应式注入**:
  配置到达后自动执行第三方脚本(仅一次)。
- **原生优先**:配置了 Chatwoot/Crisp 等脚本时,前台**只执行第三方脚本,
  由其原生渲染气泡,本站不再渲染任何按钮/面板**(消除双气泡与嵌套冲突);
  未配置脚本时才展示本站链接浮窗(Telegram/Discord/邮箱等)。

### 2. 站点 favicon 生效

- 后台「站点信息」新增**站点图标(favicon)**上传(浏览器标签页图标);
- 前台动态注入 `<link rel="icon">`(优先 favicon,留空回退站点 Logo);
- 配置经安全 URL 清洗。
