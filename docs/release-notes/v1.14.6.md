# v1.14.6

## 🐛 修复：延长 ACG-Faka 商品调试请求超时时间

**现象**：管理员通过货源商品调试接口直接请求 ACG-Faka
`/shared/commodity/items` 时，大型商品目录或上游响应较慢时可能在 30 秒处超时。

**修复**：

- 将该表单 POST 请求的超时时间从 30 秒延长到 60 秒；
- 保持其他上游驱动及支付、回调请求的超时策略不变；
- 新增回归测试，直接断言传给 HTTP 客户端的 `timeout` 为 60。
