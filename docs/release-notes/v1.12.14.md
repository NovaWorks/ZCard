# v1.12.14

## 🐛 修复:充值支付跳登录 + 登录支持用户名 + 自定义金额交互

### 1. 充值支付选渠道确认后跳登录

**根因**:`PaymentController::create` 的充值单分支用 `$request->user()` 解析登录用户,
但 `/api/payments/create` 路由**不在 `auth:sanctum` 中间件组**内,`$request->user()` 默认走
**web guard(session)**,无法解析请求头里的 Bearer token → 恒为 null → 恒返回 401
→ 前端 request.ts 拦截器跳转登录页。订单(ORD)支付无需登录,不受影响。

**修复**:充值单分支改为 `$request->user('sanctum')`(显式用 sanctum guard 解析 Bearer token)。

**验证**:充值单支付返回 `redirect_url`(200),不再 401 跳登录。

### 2. 登录只支持邮箱,而注册要用户名

**根因**:`AuthController::login` 验证 `'email' => 'required|email'` 且 `User::where('email', ...)`
硬编码邮箱匹配,无法用注册时的用户名登录。

**修复**:
- 后端:登录标识改为 `required|string`,用 `where(email)->orWhere(username)` 匹配(兼容邮箱/用户名)。
- 前端 Login.vue:标签/占位符改为「邮箱 / 用户名」,输入框 type 改 text。
- i18n:zh/en 文案同步(`emailOrUsername` / `emailOrUsernamePlaceholder` 等)。

**验证**:用户名 `admin` 登录成功、邮箱登录回归正常、错误账号正确拒绝。

### 3. 余额充值自定义金额交互

**根因**:自定义金额行点击区域只有右侧输入框可聚焦,体验差。

**修复**:改为 `<label>` 包裹(整行点击聚焦输入框),「自定义金额」文字在前、输入框 flex 占满在右(金额右对齐,大厂风格)。

**验证**:`textBeforeInput=true`、`tag=LABEL`、输入框 flex 占满。
