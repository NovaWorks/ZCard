# v1.9.10

## 🔧 本次更新内容

### 1. 商品管理列表:上架/下架状态文字

商品列表的状态列，在开关旁增加文字状态，一目了然：

- **上架** → 绿色文字
- **下架** → 红色文字

### 2. 货源管理 → 拉取上游商品(勾选导入)弹窗升级

勾选导入界面重做，分类级操作大幅提升效率：

- **分类折叠/展开**：点击分类头收起/展开该分类商品，箭头旋转动画
- **分类全选**：每个分类头有全选 checkbox，一键勾选该分类全部商品
  （支持三态：全选 / 半选 / 未选）
- **分类产品总数**：分类头右侧显示「共 X 个商品」
- **单产品/多产品勾选**保留，全局全选保留

## ⬆️ 升级

> 在线更新：后台 → 在线更新 → 检查版本 → 一键更新即可（Git-based）。

```bash
git pull origin main

```
