# v1.12.21

## ✨ 新增:公告顶部入口(点击重看) + 帮助中心后台可配置

### 1. 公告顶部入口(点击重新弹出公告弹窗)

公告内容可能包含联系方式等,弹一次后用户想再看没有入口。本次:
- **AppHeader 顶部品牌条**新增「📢 公告」入口(有公告内容时显示)。
- 点击后通过事件总线触发公告弹窗**重新弹出**。
- 首次访问仍自动弹出一次;关闭后随时可点击顶部「公告」回看。

**实现**:新增轻量事件总线 `storefront/src/utils/eventBus.ts`;
`NoticeModal` 暴露 `open()`;`AppHeader` 触发 `notice:open`;`DefaultLayout` 监听打开。

### 2. 帮助中心后台可配置

帮助中心(页脚栏4)原先只有静态文字。本次:
- 新增 `footer_help_links` 配置(链接/文本列表)。
- 后台「**页脚配置 → 帮助中心**」JSON 编辑,
  格式 `[{"title":"常见问题","url":"/orders/query"}]`(url 留空显示为纯文字)。
- storefront 帮助中心栏渲染配置内容。

**默认值**:常见问题 → /orders/query;购买须知 → 纯文字。
