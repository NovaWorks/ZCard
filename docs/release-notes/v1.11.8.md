# v1.11.8

## 🐛 修复:素材选择弹窗选中图片闪退 + 图片删除按钮难用

### 问题一:选择弹窗选中图片闪退

**现象**:在弹出素材管理选择图片(如店铺 Logo 选择)时,点击图片后页面闪退/崩溃。

**根因**:单选模式下 `toggleSelect` 点击图片即 `emit('confirm')`,同步关闭弹窗并 `destroy-on-close`
销毁 MediaManager 组件。在组件卸载与 click 事件冒泡竞态下,部分环境会触发页面崩溃。

**修复**:单选模式改为**点击选中(显示勾选),点底部「确定」返回**——与多选/管理模式统一,
不再"点击即关窗销毁组件",消除闪退竞态。

### 问题二:图片删除按钮难用

**现象**:素材管理删除图片不方便/找不到删除按钮。

**根因**:卡片操作条(预览/复制/下载/移动/删除)依赖**鼠标 hover 才显示**(opacity 0),
触屏设备无法 hover,操作按钮不可见。

**修复**:操作条改为**常驻半透明显示**(opacity 0.85),hover 时全亮(opacity 1),
鼠标/触屏都能直接看到并使用删除等操作按钮。

**验证**:
- 选择弹窗:点击图片 → 弹窗保持 + 选中高亮 → 点确定 → 关闭回填 URL,无闪退
- 删除:删除按钮常驻可见 → 点击 → 确认 → 删除成功
