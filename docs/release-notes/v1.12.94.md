# v1.12.94

## ⚡ 新增：货源定时任务设置（采集/价格/上下架独立间隔 + 时间窗口 + 请求节流）

**反馈**：一直在跑 `php artisan queue:work` 的站点，上游货源会因为请求太频繁直接失败
（限流/封禁）；而旧的自动同步是**硬编码每小时**跑一次，无法调整频率，也无法控制执行时段。

**方案**：把「货源自动同步」升级为**按货源配置的定时任务计划**——站长在后台
「货源管理 → 设置任务」弹窗里，为每个货源分别设置三类任务的执行间隔与时间窗口，
调度器每分钟检查、到期才派发；同一个货源同一时刻只执行一个任务（采集优先），
从机制上把对上游的请求压力降下来。

### 1. 后台「货源管理 → 设置任务」（查看任务旁的新按钮）

弹窗内按货源配置：

- **总开关**：关闭后该货源不再自动采集/同步价格/同步上下架（手动同步不受影响）；
- **请求间隔（秒）**：每次请求上游之间等待的秒数（0=不等待）。上游对请求频率敏感时
  建议设置 2~5 秒，防止被限流——这是针对「频繁请求被打挂」最直接的兜底；
- 三类任务各自可配置：**启用开关、执行间隔（分钟，带 15 分钟~1 天的快捷预设）、
  执行时间窗口**（几点到几点，可添加多条，留空=全天，支持跨天如 22:00~06:00）；
- 采集商品额外可选 **增量 / 全量** 模式。

表格新增「定时任务」摘要列（启用状态 + 各任务间隔一目了然）；
任务弹窗里的每条任务新增类型标签（采集/价格/上下架）。

### 2. 三类定时任务（同一异步任务，三种 scope）

| 类型 | 行为 | 建议频率 |
|---|---|---|
| **采集商品** | 完整/增量同步：新建商品 + 更新名称/描述/封面/分类 + 价格/库存 + 全量对账删除 | 较长（如每 6 小时） |
| **同步价格** | 只更新已有商品的售价/成本/库存缓存，**不建新商品、不改元数据、不对账**；遵守自动跟价与手动价保护 | 较短（如每 30 分钟） |
| **同步上下架** | 只更新已有商品的隐藏状态（上游失效→下架，恢复→上架），**不补查库存**，请求量最小 | 如每 60 分钟 |

### 3. 调度器改造

- 新增命令 `supply:scheduled-sync`，由 Laravel Scheduler **每分钟**触发
  （替换 v1.12.72 硬编码的每小时增量同步闭包），按每个货源的 `settings.schedule` 计划判断是否到期；
- 到期判断基于新列 `last_collect_at / last_price_sync_at / last_status_sync_at`（派发成功后才记录，
  失败下个周期自动重试）；
- 同一货源同一时刻只派发一个任务；**采集已覆盖价格/上下架**，同一周期内采集优先，
  价格/上下架等采集结束后按各自间隔再执行。

### 4. 旧版兼容

- 只配置了旧 `auto_sync=true` 的货源（无 schedule 配置）自动按「每小时增量采集」处理，
  行为与 v1.12.93 完全一致，升级无感知；
- 手动「同步商品 / 覆盖调价」不受影响（仍走采集 scope）。

### 5. 数据库变更（需执行迁移）

- `supply_sources` 新增：`last_collect_at`、`last_price_sync_at`、`last_status_sync_at`；
- `supply_sync_tasks` 新增：`scope`（任务类型，默认 collect）+ 组合索引。

### 6. 测试

新增 38 个用例（调度命令派发/防重/优先级/时间窗口/总开关、计划解析与旧版兜底、
价格与上下架 scope 的售价保护/不改元数据/不越权建商品）；**全套 410 项测试全绿**，
Pint 通过。

## 升级与使用

- 通过后台「在线更新」或 `git pull && composer install --no-dev` 升级，然后执行
  `php artisan migrate --force`；
- Cron（每分钟 `php artisan schedule:run`）与 `queue:work` 均已要求常驻，**无需改动服务器配置**；
- 升级后到「货源管理 → 设置任务」为每个货源配置间隔；上游限流严重的站点建议
  采集 6 小时 + 价格 30 分钟 + 上下架 60 分钟，并设置请求间隔 2~5 秒。
