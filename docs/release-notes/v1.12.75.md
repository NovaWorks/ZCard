# v1.12.75

## 🐛 修复:订单详情增强未生效(v1.12.74 前端产物缺失) + 详情排版优化

**反馈**:v1.12.74 发布的订单详情增强(上游链接/利润/单价)在后台看不到,
且详情排版文字挤在一起。

**根因**:v1.12.74 前端构建脚本在合并模板时提前失败退出,增强的模板区块
(财务信息/上游货源信息/重新拿货按钮)**从未写入源码文件**,发布的产物
只包含接口层改动 —— 后端有数据,前端详情弹窗没有渲染。

**修复**:
1. **重新写入全部增强模板**(本次已验证落盘):
   - 财务信息区:金额/数量/单价/成本/成本单价/利润(+利润率),正负利润彩色高亮;
   - 上游货源信息区:货源名称/上游单号/上游商品链接(可点击);
   - 操作列:「手动发货」放开到上游订单 + 「重新拿货」按钮。
2. **详情排版优化**:
   - 弹窗宽度 600 → **720px**;
   - 分区标题(订单信息/财务信息/上游货源信息)色条分隔;
   - 订单号/商品名/SKU/上游链接等长文本**占满整行**,不再挤压;
   - 标签列固定宽度,内容自动换行;
   - 财务区 3 列紧凑布局。

## 验证

- 后端接口字段(unit_price/profit/upstream_*)自 v1.12.74 已就绪,全量测试 285 通过;
- sysadmin 构建通过,产物已重建(本次为纯前端修复,后端无改动)。
