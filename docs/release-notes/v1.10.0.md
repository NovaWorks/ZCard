# v1.10.0

## ✨ 新功能:素材管理(Media Library)

统一系统内所有图片上传与选择,新增「素材管理」模块(后台 → 系统设置 → 素材管理):

- **图片上传**:拖拽/点击、多文件、上传进度,支持 JPG/PNG/WEBP/GIF/SVG
- **图片分类**:分类增删改、重名校验、长度限制(30字);删除有图分类前必须先迁移图片到其它分类,杜绝孤立数据
- **图片管理**:名称模糊搜索、排序(上传时间/名称/大小)、卡片式展示(缩略图+名称+日期+大小)
- **图片操作**:预览(全屏放大/缩小/旋转/左右切换)、复制链接、下载、移动分类、删除,支持批量移动/批量删除
- **统一选择弹窗**:新增可复用 `MediaPicker` 组件(单选/多选),所有涉及图片上传/选择的表单统一弹出素材管理弹窗;
  已接入店铺 Logo、分类图标等现有图片字段(保留原 URL 输入与直传按钮)

**数据库**:新增 `media_categories`、`media` 两张表(含 softDeletes),升级时自动迁移。

## 🐛 修复:货源拉取商品分类名显示"分类 #4"

**现象**:货源管理 → 拉取商品,分类名一直显示「分类 #4」之类的占位,看不到上游设置的分类名。

**根因**:`previewProducts` 从未调用驱动的 `listCategories()`,直接硬编码 `'分类 #' . $catCode`。

**修复**:拉取商品时调用 `listCategories()` 构建上游分类映射,并让三个驱动(AcgFaka/dujiao-next/ZCard)
在商品数据中携带真实分类名;无分类商品归入「未分类」。

## 🐛 修复:采集商品详情页图片无法放大预览

**现象**:主图可以放大旋转,但详情描述里(采集商品内嵌的)图片点击无反应;且相对路径图片在本地 404。

**根因**:
1. 富文本描述(`rich-content`)内的 `<img>` 没有绑定放大预览事件;
2. 同步时描述里相对路径图片(`/assets/...`)未拼接上游域名,在前台解析成本站 → 404。

**修复**:
1. 前台详情页描述区图片点击 → 收集描述内全部图片打开全屏预览(放大/缩小/旋转/上一张/下一张/关闭);
2. 同步服务新增描述图片 URL 归一化,重新同步后相对路径自动拼接上游 base_url。
