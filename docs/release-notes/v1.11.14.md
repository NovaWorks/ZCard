# v1.11.14

## 🐛 修复:素材选择弹窗(从上传图片处进入)没有删除图片功能

**现象**:从需要上传图片的地方(如站点信息 Logo、分类图标、商品图等)点击「选择图片」打开的**素材选择弹窗**里,
图片卡片没有任何删除/移动/下载入口,只能选择,无法管理素材。

**根因**:素材管理卡片底部的操作栏(复制/下载/移动/删除)用 `v-if="!selecting"` 控制,
而选择弹窗是 `selecting=true` 模式 → 操作栏被隐藏,弹窗内无法删除图片。

**修复**:底部操作栏与缩略图 hover 操作条改为**所有模式常驻显示**:
- 选择弹窗/管理模式均显示「🔗 复制 / ⬇ 下载 / 📁 移动 / 删除」
- 操作栏按钮 `@click.stop`,点击不会触发图片选中(选择弹窗中选择功能不受影响)

**验证**(本地实测,从站点信息 → 选择图片弹窗):
1. 弹窗内卡片显示底部操作栏「🔗⬇📁删除」
2. 点击删除 → 确认弹窗 → 图片删除成功,弹窗保持打开可继续选择
3. 点击卡片区域仍正常选中,选择功能无回归
