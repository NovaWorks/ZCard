# v1.12.6

## 🐛 修复:分类下看不到商品(父分类不含子分类商品 + 手机看不到子分类)

### 问题
客户站(kmigo.com)商品挂在子分类下(如 谷歌邮箱 → 企业邮箱/个人邮箱),
但:
1. **后端**:按父分类筛选只查 `category_id = 父分类`,查不到子分类的商品 →
   点击「谷歌邮箱」显示「暂无商品」
2. **前端(sidebar 模式)**:手机端侧边栏隐藏后,兜底分类条只渲染一级分类,
   没有子分类入口 → 用户无法选择子分类 → 子分类下的商品永远看不到

### 修复
1. **后端** `ProductController::index`:按分类筛选时,若为父分类则
   `whereIn(category_id, [父分类 + 全部子分类])`,父分类下能查到所有子分类商品。
2. **前端** Home.vue 移动端分类条:含子分类的一级分类可点击展开子分类
   (横向滚动),子分类可直接选择;同时提供「查看全部」入口。
   与桌面端 sidebar 树的子分类展开逻辑一致。
