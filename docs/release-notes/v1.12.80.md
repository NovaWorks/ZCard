# v1.12.80

## 🐛 修复:商品列表「上游价格/加价」列未生效 + 加价显示 0 的误导

**反馈**:商品列表(/admin#/product/list)看不到完整的上游价格/加价信息,
且加价显示 ¥0.00。

**根因(两处)**:
1. v1.12.79 的列表列(上游价格/加价/链接)因构建脚本中断**未写入源码**,
   发布产物不含该列(与 v1.12.74 同类问题)——本次已完整落盘并验证;
2. 加价计算在**上游售价快照缺失**(未同步)时回退成本价,若商品是平价
   (成本=售价)则显示 ¥0.00,容易误解为"加价没生效"。

**修复后的显示逻辑**(上游货源商品):
- **上游售价**:同步快照(¥X.XX);未同步过显示 ¥0.00(快照为 0);
- **加价**:本地售价 - 上游售价,显示金额(+比例%);
  - 基准未知(未同步且无成本)→ 显示**「待同步」**(不再显示 0 误导);
  - 加价为 0(平价)→ 显示**「平价」**标签;
- **上游商品链接**:列内直达上游商品页;
- 本地商品该列显示「—」。

**提示**:若显示「待同步」或「上游价 ¥0.00」,说明该商品尚未完成新一轮同步
(上游售价快照在 v1.12.79 后才有)。触发一次同步(货源→同步商品,或等定时任务)
后即显示准确的上游售价与加价。

- 列/辅助函数/样式已确认写入源码(事后 grep 验证);
- sysadmin 构建通过,产物已重建;
