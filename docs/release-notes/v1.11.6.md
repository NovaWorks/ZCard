# v1.11.6

## 🐛 修复:后台登录滑块验证默认"验证成功"且无法滑动

**现象**:后台登录页的滑块验证条默认就显示"验证成功"(绿色),且无法拖动。

**根因**:登录页 `views/auth/login/index.vue` 中滑块验证状态初始值被硬编码为 `true`
(`const isPassing = ref(true) // ZCard: 跳过滑动验证(开发期)`),这是早期开发期跳过验证留下的。
`value=true` 导致:
- 滑块条渲染成成功状态(绿色 + success 图标)
- `ArtDragVerify` 组件收到 `value=true` 后,拖拽逻辑 `if (!props.value)` 直接跳过 → 无法滑动

**修复**:`isPassing` 初始值改回 `false`,用户必须真实拖动滑块到末端才能通过验证,
拖动完成进度条变绿、显示"验证成功"。

**验证**:本地实测完整流程:
1. 初始状态:显示"按住滑块拖动",蓝色进度条,滑块在起点
2. 拖动到末端:显示"验证成功",进度条变绿(#57D187)
3. 未通过时点击登录会提示拖动滑块
