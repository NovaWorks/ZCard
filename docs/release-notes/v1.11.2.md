# v1.11.2

## 🐛 修复:素材管理删除图片无效

**现象**:素材管理(图片资源管理)中选中图片后点击删除,删除不了;批量操作栏也不出现。

**根因**:素材管理页面(管理模式)`media-manager` 组件中,点击图片卡片的 `toggleSelect` 函数
第一行 `if (!selecting.value) return` —— 管理模式(非选择弹窗)下 `selecting=false`,
点击卡片直接返回,**无法选中图片**,因此批量操作栏(含批量删除)永远不会出现。

**修复**:
1. `toggleSelect`:管理模式也支持点击选中(切换勾选状态),只有"选择模式+单选"才保持点击即确认
2. 管理模式卡片右上角显示勾选标记(checkbox),选中后顶部出现「移动/批量删除/取消选择」操作栏
3. 单张/批量删除的确认弹窗逻辑收敛到 try/catch 内,取消不再产生未处理异常

**验证**:素材管理页点击图片→显示选中高亮+勾选标记→批量操作栏出现→批量删除成功(数据库记录与磁盘文件均清除)。
