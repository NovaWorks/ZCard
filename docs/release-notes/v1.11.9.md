# v1.11.9

## ✨ 优化:收银台支付方式显示具体支付方式(支付宝/微信)而非通道名

**背景**:收银台「支付方式」区域显示的是**支付通道名称**(如"易支付聚合""码支付"),
而非用户实际使用的支付方式。参考 dujiao-next / acg-faka 的收银台,应显示**具体支付方式**
(支付宝/微信支付/PayPal/USDT 等)及对应图标。

**修复**:
1. **后端**:`PaymentDriver` 契约新增 `getPayTypes(array $config)` 方法,各驱动声明支持的支付方式标识:
   - 支付宝驱动 → `alipay`;微信支付驱动 → `wechat`;PayPal → `paypal`;Stripe → `stripe`;USDT 系列 → `usdt`
   - **易支付 / 码支付聚合通道** → 读取后台配置的 `type` 多选(可同时支持 alipay+wxpay+qqpay 等)
   - `/api/payments/channels` 接口返回 `pay_types` 字段
2. **前端**:收银台(Checkout)与支付页(Pay)按 `pay_types` 展示支付方式:
   - 每个通道显示对应支付方式图标(💰支付宝/💚微信/🅿️PayPal/₮USDT)+ 名称
   - 聚合通道同时展示多个支付方式(如"支付宝 / 微信支付")

**验证**(本地实测):
- 易支付聚合通道 → 显示 💰💚「支付宝 / 微信支付」
- 码支付(alipay 配置) → 显示 💰「支付宝」
- PayPal → 显示 🅿️「PayPal」
