# v1.12.36

## ✨ 新增:商品管理按「货源商」筛选(issue #3)

**需求**:商品太多时,某供货商跑路需下架其全部商品,但无法一下子搜寻到。

**实现**:
- 后端 `Admin ProductController::index` 支持 `upstream_source_id` 筛选参数。
- 后台「商品管理 → 搜索栏」新增「**货源商**」下拉(选项来自货源列表,
  仅显示上游供货商品归属的货源)。
- 配合现有批量操作:筛选出该货源商全部商品 → 勾选 → 「下架」一键处理。
- 商品列表 API 参数类型同步(ProductListParams.upstream_source_id)。
