# v1.12.32

## ✨ 新增:顾客购买后可发表真实评价(入口补齐)

**现象**:后台「允许评价」开启后,顾客购买完毕没有评价入口——
评价展示(商品页)与提交接口(POST /api/reviews)早已存在,但前端从未调用提交接口。

### 本次实现

**后端**:
- `GET /api/reviews/eligibility/{productId}`(需登录):返回当前用户对该商品的
  可评价状态(`allow_post_review` / `can_review` / `reviewed` / 可挂靠的 `order_id`)。
- `OrderService::myOrders` 返回新增 `id`、`product_id`、`reviewed`(该订单是否已评价),
  供「我的订单」展示评价入口。
- `Order` 模型补 `reviews()` 关联。

**前端(storefront)**:
- **我的订单**:已支付且未评价的订单显示「写评价」按钮(受后台 `allow_post_review`
  控制),弹窗内选星级 + 填内容 → 提交 → 成功后标记已评价。
- **商品详情页**:登录用户购买过该商品且未评价时,购买区下方显示「写评价」入口,
  同样弹窗提交。
- 提交走既有 `POST /api/reviews`(后端校验:订单归属/已支付/未重复评价/开关)。

### 验证

- `tests/Feature/ReviewEligibilityTest`(4 用例):paid 未评价可评 / 已评价不可评 /
  开关关闭不可评 / myOrders 含 product_id+reviewed。
- 全量 198 通过 / 622 断言。
- storefront typecheck + build 通过,产物已更新。
