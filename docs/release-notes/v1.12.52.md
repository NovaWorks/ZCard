# v1.12.52

## ✨ 顶部品牌条文案后台可自定义(中英双语)

**需求**:前台顶部品牌条(标语 / ✓安全支付 / ✓隐私保护)改为后台可配置,
支持中文与英文。

**实现**:
- **后端** `StorefrontConfig` 新增 6 个配置项(带默认值 = 现文案):
  `brand_slogan` / `brand_slogan_en` / `brand_secure` / `brand_secure_en` /
  `brand_privacy` / `brand_privacy_en`。
- **后台**(店铺设置 → 站点信息 → 新增「顶部品牌条文案」区块):
  中英各一组输入框(标语/安全支付/隐私保护)。
- **前台**(AppHeader):
  - 英文界面优先 `*_en`,缺省回退中文;中文留空回退前端 i18n 默认文案。
  - 语言切换即时生效。
