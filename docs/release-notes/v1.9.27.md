# v1.9.27

## ✨ 本次更新内容

### 1. 优化:货源对接页面排版

「货源对接」页的「拉取商品」弹窗排版优化（此前文字拥挤）：
- **定价策略区**改为两行布局（策略标题 + 选项/参数独立成行，分隔线分组），不再一行挤满
- **分类映射行**增大间距，上游分类名/选择器宽度放宽（220→300px），允许换行
- **商品列表行**名称支持最多两行省略（不再强制单行截断），间距加大
- 弹窗宽度 780px → 880px，顶距放宽

### 2. 修复:后台「默认视图」缺少双栏选项

「店铺设置 → 显示设置 → 默认视图」只有网格/列表两项，前台 ViewSwitcher 却有双栏——后台无法配置双栏。
已补充「双栏」选项（grid / list / dual 三选），保存后前台首页商品列表即按所选视图渲染。

> 提示：前台右上角「视图切换器」会记住用户的手动选择（本地存储），此时以后台默认视图为准需清除浏览器该记录（或用户手动点回目标视图）。
