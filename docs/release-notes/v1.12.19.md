# v1.12.19

## ✨ 新增:公告弹窗 + MD/HTML 富文本编辑器(参考 guopi.org)

### 变更内容

**后台(sysadmin)**:
- 「系统运维 → 店铺公告」输入框由纯文本框改为 **ArtWangEditor 富文本编辑器**
  (复用商品描述的 wangEditor,支持 Markdown 源码 + HTML 模式 + 图片上传 + 所见即所得预览)。
- 公告内容以 HTML 形式保存。

**前台(storefront)**:
- 移除原顶部滚动公告横幅,改为 **公告弹窗**:
  - **访客首次访问自动弹出**(居中模态框 + 半透明遮罩,参考 guopi.org)。
  - HTML 内容渲染(v-html + XSS 过滤,复用商品描述同款 sanitize)。
  - 富文本样式(标题/列表/引用/代码块/表格/图片等)。
  - 「我知道了」按钮 + 遮罩点击关闭。
  - 关闭后本次会话不再弹(localStorage 记忆)。

### 多语言

### 使用说明

后台「系统运维 → 店铺公告」用富文本编辑器编辑公告(支持 Markdown/HTML),
保存后**访客首次访问站点时弹出**。留空则不弹。
