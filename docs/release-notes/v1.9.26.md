# v1.9.26

## 🐛 修复:前台分类图标图片不加载

**现象**：后台分类使用 ImagePicker 上传图片作为图标（存 `/storage/xxx.png` 或完整 URL）时，
前台分类导航把图片路径当**纯字符文本**显示（如直接显示 `/storage/products/xxx.png`），
并未渲染为图片。

**根因**：前台 `CategoryNav` 组件对 icon 一律按文本（emoji）渲染，没有像后台那样区分
图片 URL 与 emoji 字符。

**修复**：
- 前台分类导航（顶部胶囊 / 左侧树 / 抽屉模式及其子分类面板）识别图片型图标
  （`http(s)://` 或 `/storage/` 开头）→ 渲染为 `<img>`，emoji 仍按文本显示
- 开发环境 `vite.config.ts` 补充 `/storage` 代理（dev 预览分类图标/商品图）
