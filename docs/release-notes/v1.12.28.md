# v1.12.28

## 🐛 修复:收银台已选余额支付仍提示「请选择支付方式」

**根因**:余额支付通道 id=0,收银台提交校验用 `!selectedChannelId.value`
判断,`0` 被当作 falsy → 即使已选中余额支付也误报「请选择支付方式」。

**修复**(`storefront/src/views/Checkout.vue`):
- 提交校验与提交入口改为显式 `selectedChannelId.value === null` 判断。
- 顺带修复余额展示双符号(`Balance: ¥¥100.00` → `Balance: ¥100.00`,
  文案与金额格式化去重)。

**验证**:Playwright 端到端复现原场景 —— 登录 → 商品 → 收银台选「余额支付」
→ 提交 → **成功跳转支付结果页**(不再提示选择支付方式),余额扣减、订单 paid。
