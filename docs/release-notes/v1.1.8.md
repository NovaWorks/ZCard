# v1.1.8

## 🐛 修复:在线更新 git pull 失败(dubious ownership)+ 版本号不更新

### 问题

在线更新提示"更新成功",但:
- 代码根本没更新(`git pull` 失败)
- 版本号仍显示 1.0.0

### 根因(日志实锤)

```
fatal: detected dubious ownership in repository at '/www/wwwroot/kmigo.com/ZCard'
To add an exception for this directory, call:
    git config --global --add safe.directory /www/wwwroot/kmigo.com/ZCard
```

`chown -R www:www` 修复权限后,git 目录属主变为 www,但执行 git 命令的进程身份不一致 → git 出于安全**拒绝操作** → `git pull` 没拉到任何代码。

后续 composer install 跑的是旧代码,但日志没明确报"失败"(git 的 dubious ownership 警告 exit code 可能是 0),程序误判为"更新成功"。

### 修复

1. **`ensureGitSafeDirectory()`**:git 操作前自动执行 `git config --global --add safe.directory`,消除 dubious ownership 拦截(幂等,可重复执行)
2. **加强错误检测**:`git pull` 输出含 `fatal:` 也判定为失败(之前只检测 `CONFLICT` 和 `error:`),避免误报"成功"
3. **VERSION 文件更新为 1.1.8**:git pull 成功后 VERSION 文件随代码更新,版本号自动跟上

## ⬆️ 升级

> ⚠️ **本次升级必须用命令行,不能用在线更新**(因为在线更新的修复就在本次更新里)。

```bash
cd /www/wwwroot/kmigo.com/ZCard

# 先解决 dubious ownership(一次性)
git config --global --add safe.directory /www/wwwroot/kmigo.com/ZCard

# 拉取最新代码
git pull origin main

# 权限 + 缓存
chown -R www:www storage bootstrap/cache vendor
rm -f bootstrap/cache/*.php
php artisan optimize:clear
/etc/init.d/php-fpm-84 restart
```

更新后:
- 版本号正确显示 **v1.1.8**
- 以后在线更新能正常 `git pull`(自动处理 safe.directory)

无数据库变更。
