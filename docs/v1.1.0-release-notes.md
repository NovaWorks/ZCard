## 🔄 货源对接(Supply Integration)

本次版本新增完整的**双向货源对接**能力:既可以对接外部系统(dujiao-next / acg-faka / 另一个 ZCard)作为上游拿货,也可以对外开供货 API 让别人对接本站拿货,还能**自己对接自己**做货源中转。

### 🔼 作为上游(对外供货)
- **对外供货 API**(`/api/supply/*`):自定义 HMAC-SHA256 四头签名协议(双密钥 + nonce 防重放 + timestamp 窗口)
- **供货账号管理**(sysadmin「供货账号管理」页):创建账号自动生成 API Key/Secret(明文仅展示一次)、重置密钥、充值预存、账本流水、启停
- **SKU 级专属定价**:每个账号 × 每个 SKU 设独立拿货价(账号维度 + 商品维度两个管理入口)
- **预存扣费**:下单自动从预存余额扣费,原子事务 + 行锁防超卖 + 幂等(同订单号不重复扣)
- **动态限流**:每账号每分钟请求数可在设置页配置,改了立即生效

### 🔽 作为下游(对接上游拿货)
- **驱动化架构**:三种上游统一接口(`DujiaoNextDriver` HMAC / `AcgFakaDriver` MD5 / `ZCardDriver` 自定义协议),加新上游零前端改动(驱动自描述 configSchema)
- **货源管理**(sysadmin「货源管理」页):选平台 → 凭证字段自动切换 → 测试连通 → 同步商品;支持同时对接多个上游
- **商品同步 + 售价保护**:全量/增量同步上游商品到本地,运营可自由定价(可贵可便宜),再次同步只更新成本不动售价
- **客户下单全链路**:客户买上游商品 → 跳过本地锁卡 → 付款后自动去上游拿货(同步试→异步回退) → 卡密加密存储 + 顾客订单页可见
- **发卡模式**:同步发卡(下单即拿)/ 异步发卡(排队拿货)可在货源设置页选
- **拿货失败处理**:人工介入 / 自动退款可选
- **库存模式**:本地缓存(同步时拉取) / 展示充足可选

### ⚙️ sysadmin 设置页
- 「设置 → 货源对接」Tab:总开关 + 上游/供货方向独立开关 + nonce 存储 + 限流 + 签名时间窗口(网页可配,改了立即生效)
- 「货源管理」页:货源 CRUD + 凭证加密存储 + 测试连通 + 同步商品 + 库存/发卡/失败/定价设置
- 「供货账号管理」页:账号 CRUD + key 生成 + 充值 + 账本

## 🐛 重要修复

- **[阻塞] 客户买上游商品下单必崩** — OrderService 无条件锁本地卡,上游商品无卡→崩溃。改为上游商品跳过锁卡,付款后拿货
- **[严重] 上游卡密明文存储 + 顾客看不到** — Card.content 改用 CardCipher 加密 + 写 OrderDelivery 明文快照
- **[严重] supply_sources.credentials 列溢出** — encrypted:array 存加密字符串,MySQL json 列拒绝。改 text 列
- **[严重] supplier_accounts.api_secret 列溢出** — Crypt::encryptString 后约 312 字符,原列 128 不够。改 500
- **[严重] supply_orders.callback_url 列溢出** — 验证允许 500 但列默认 255。改 500
- **SKU 级专属价下单不生效** — createOrder 硬编码 null,改为解析 sku_id 走 SKU 级价
- **充值幂等键熵不足** — random_int(1000,9999) 改 bin2hex(random_bytes(8))
- **硬编码中文未走多语言** — 订单错误消息改 __()
- **DeliveryService 对上游订单误跑** — 加守卫跳过
- **在线更新图标不显示** — ri:upgrade-line 不存在,换 ri:download-cloud-2-line
- **版本号不跟随 release** — 改运行时 git describe --tags 自动同步
